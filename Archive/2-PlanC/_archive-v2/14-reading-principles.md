# 독해원칙 — 2026-09-07 고정

> 🔴 이 파일은 `02-working-rules`를 대체하지 않고 **보완**한다. 다섯 층 구분(①정의 ②측정 ③검증 ④저자해석 ⑤우리추론)은 그대로 적용된다.
> 📌 이 원칙들은 **원문 판정과 선행연구 정리 전체에** 적용된다.

---

## 1. 🔴 목적은 critique가 아니라 differentiation / positioning이다

**우리 논문의 목적은 기존 연구를 평가하거나 비판해서 자리를 만드는 것이 아니다.**

### ❌ 원칙적으로 피하는 표현

| |
|---|
| 기존 연구는 **실패했다** |
| 기존 연구는 **해결하지 못했다** |
| 기존 접근은 **작동하지 않는다** |
| 기존 연구의 **전제가 잘못됐다** |
| 기존 연구의 **한계는 ○○다** |

🔴 **위 표현은 원저자가 직접 그렇게 규정했거나, 비교 가능한 직접 증거가 있을 때만 사용한다.**

### 🔴 함축 표현도 쓰지 않는다

| ❌ | 왜 |
|---|---|
| **우회로(workaround)** | 「정면 해결 실패」를 함축 |
| **작동을 멈추는 조건** | 실패를 전제 |
| **무력해진다 · 흔들린다** | 동일 |
| 「저자가 그 분석을 하지 않았다」를 **태만처럼 서술** | 연구 범위 선택을 결함으로 읽음 |

⭕ **중립 표현으로 바꾼다** — 「기존 개인평가에서 특정 정보가 개인판단에 사용될 수 있었던 조건과 정보적 의미가 Human-AI 생산구조에서도 동일하게 유지되는가」

### 각 선행연구에 대해 구분하는 다섯

| # | |
|---|---|
| **1** | 그 연구가 실제로 **무엇을 설명했는가** |
| **2** | 어떤 **대상 / 관계 / 조건 / 수준**을 다뤘는가 |
| **3** | 우리의 최초 문제와 **어디에서 연결되는가** |
| **4** | **어디에서는 동일하지 않은가** |
| **5** | 그 차이가 **이미 다른 문헌에서 설명되어 있는지**, 아니면 **별도의 설명이 필요한지** |

### ⭐ 문장 형식

> **선행연구 A는 X를 설명한다.**
> **현재 우리의 관심은 Y이다.**
> **X와 Y는 Z 지점에서는 연결되지만 W 지점에서는 동일하지 않다.**
> **따라서 Y가 기존 설명의 적용범위 안에 있는지, 또는 별도의 설명이 필요한지를 확인한다.**

### 📌 실제로 확인된 것 — 저자들이 스스로 범위를 적어두었다

`15-mapping-H-I-theta`를 만들며 드러난 사실이다.

| 문헌 | 저자 자신의 범위·미결 진술 |
|---|---|
| **Alchian & Demsetz (1972)** | 전문·예술 노동에서는 활동 관찰이 좋은 단서가 아니며, 그 영역에는 재량 확대·이익분배·파트너십이 쓰인다 (p.786) |
| **Rothstein (1990)** | 정확성이 아니라 신뢰도를 다루었다. 진점수를 알 수 없기 때문이다 (p.327) |
| **Latham & Wexley (1977)** | 접촉량에 따른 도구 선택은 향후 연구가 판단해야 한다 (p.268) |
| **Uribe 등 (2022)** | 직접 관찰이 어려운 세팅에서 효과가 클 수 있고, 상호의존성이 낮으면 덜 중요할 수 있다 |

⭕ **우리가 「한계」로 지목할 필요가 없다. 저자들이 그은 선 옆에 우리 현상을 놓아보는 것이 우리 작업이다.**

## 2. 🔴 I→θ를 단일 화살표로 자동 해석하지 않는다

**최소한 다음 다섯 관계를 구분한다.**

| # | 관계 |
|---|---|
| **1** | **information formation / observability** |
| **2** | **information → evaluator judgment** |
| **3** | **observed information → researcher-estimated latent target** |
| **4** | **evaluator judgment → underlying target accuracy / validity** |
| **5** | **rating reliability 등 measurement property** |

🔴 **한 문헌이 이 중 하나를 검증했다고 해서 나머지 관계까지 검증된 것으로 해석하지 않는다.**

⚠️ **그리고 이 다섯이 완전한 목록도 아니다.** `15-mapping` §⑥에서 확인된 것처럼, **개인 target이 없는 연구**(Steyvers 2022)는 다섯 어디에도 정확히 들어가지 않는다.

## 3. 🔴 H를 두 칸으로 분리한다

| 칸 | 내용 |
|---|---|
| **H-A** | **Work / production structure** |
| **H-B** | **Evaluation / inference / research structure** |

📌 **이유** — production structure, work structure, evaluation design, research design, contracting structure가 한 칸에 섞이면 **「생산구조 변화」와 「평가정보 구조 변화」를 혼동한다.**

⚠️ **어느 한쪽이 핵심 분석대상이 아닌 문헌도 있다** — Rothstein은 H-B만, A&D는 H-A가 명확하고 H-B는 이론적이다.

---

## 4. 🔴 θ는 placeholder다

**θ = 「관찰정보를 바탕으로 판단·추정하려는 개인의 특성·성과·기여 등의 대상」**

| 원칙 | |
|---|---|
| 🔴 | **latent psychological construct만을 뜻하지 않는다** |
| 🔴 | **관측값을 θ 칸에 넣지 않는다.** I와 θ의 구분이 무너진다 |
| 🔴 | **서로 다른 θ를 「개인성과」 하나로 합치지 않는다** — performance / ability / contribution / marginal productivity / firm-value contribution / rating reliability를 구분한다 |
| 🔴 | **rating의 측정속성은 θ가 아니다.** 개인에 대해 판단하려는 대상이 아니라 rating의 성질이다 |
| ⭕ | **다만 상위 수준에서 관계가 있을 가능성까지 닫지 않는다** |

## 5. 🔴 논문 전체 단일 판정을 하지 않는다

❌ **「이 논문이 우리 연구에 맞는다/안 맞는다」**
❌ **논문 하나에 Direct / Adjacent / Exclude 하나를 부여**

⭕ **대신 「무엇에 대해 Direct인가」를 관계별로 기록한다.**

**예 — Steyvers 등 (2022)**

| 무엇에 대해 | 판정 |
|---|---|
| Human-AI output combination | 🟢 **Direct** |
| interactive joint production | 🔴 No |
| individual ability inference | 🔴 No |
| organizational appraisal | 🔴 No |
| production-structure 비교 | 🟡 **Structural relevance** |

🔴 **하나의 논문이 어떤 관계에는 Direct이고 다른 관계에는 무관할 수 있다.**

---

## 6. 🔴 Human-AI를 하나의 H로 묶지 않는다

⚠️ **현재까지 확인한 다섯 편의 H-A가 서로 다르다** (`15-mapping` 참조).

| H-A | 문헌 |
|---|---|
| 인간‖AI 독립 수행 → 연구자 결합 | **Steyvers (2022)** |
| 인간 초기 → AI 권고 → 인간 최종 | **Almog (2025)** |
| 개인 과업 + 선택적 AI 호출 | **Wu HCOMP · Wu HHAI (2026)** |
| 반복 상호작용 | **Kim 등 (2026)** |

🔴 **어느 하나를 지금 「진짜 H₂」로 선택하지 않는다.**

📌 **반복적 Human↔AI joint production은 최초 현상에 가까운 중요한 구조지만, 그것만을 포함조건으로 삼지 않는다.** 상호작용이 거의 없어도 인간과 AI의 산출이 결합되어 combined performance가 만들어질 수 있고, 그것이 개인평가에서 무엇을 의미하는지는 **별도 문제**일 수 있다.

⭕ **output과 process를 모두 열어둔다.**

## 7. 🔴 두 종류의 오류를 동시에 경계한다

| | 오류 | 판단 |
|---|---|---|
| **A** | **너무 빨리 논문으로 만들기** — 아직 검증되지 않은 전제를 고정하고 IV/DV/model/gap을 만드는 것 | 🔴 **Plan A·B·C 제1후보가 모두 이렇게 진행됐다** |
| **B** | **끝없이 근본으로 내려가기** — 현재 현상을 설명하는 데 필요하지 않은 전제까지 계속 해체하여 연구문제로 돌아오지 못하는 것 | ⚠️ 경계 대상 |

**매 단계의 판단 기준**

> **「이 문제를 확인하지 않으면 최초 질문을 학문적으로 설명할 수 없는가?」**

⭕ **아니라면 흥미롭더라도 별도 open item으로 남기고 진행한다.**

### 🔴 시간에 대한 원칙

**속도와 현실적인 논문 일정은 중요하다.** 그러나 **「몇 라운드 뒤에는 IV/RQ를 확정한다」와 같은 시간 기준을 epistemic stopping rule로 사용하지 않는다.**

| 시간이 영향을 주는 것 | 시간이 근거가 될 수 없는 것 |
|---|---|
| 어떤 문헌을 먼저 볼지 | 🔴 확인되지 않은 전제를 사실로 채택 |
| 어떤 불확실성을 먼저 제거할지 | 🔴 반대 증거가 있는데 탐색 종료 |
| 어떤 질문을 우선 판별할지 | 🔴 일정 때문에 evidence level을 높이기 |

⭕ **중요한 것은 「몇 편/몇 라운드를 더 볼 것인가」보다 「현재 어떤 불확실성을 판별하면 연구방향에 대한 의사결정이 가능해지는가」다.**

## 8. 🔴 research → meeting content

**교수 의견은 중요한 입력이지만 최초 문제의 구조를 결정하는 최고위 전제는 아니다.**

⚠️ **`meeting → research structure`가 아니다.** 면담에서 확인되는 내용을 현재 탐색의 상위 조건으로 두지 않는다.
