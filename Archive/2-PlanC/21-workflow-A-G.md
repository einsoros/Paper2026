# 연구방향·모형 확정 — 단계 A~G 작업지도

> 🔴 **2026-09-10 연구자 지시 전문이다. 요약하지 않고 그대로 보존한다.**
> 🔴 **표기 통일 — 원문의 `Header A~G`는 「단계 A~G」로 적는다.** 이 프로젝트에는 이미 **확보 문헌 두 구역**을 가리키는 「헤더 A·B」가 있었고(`20-` §6 「작업 ③ — 헤더 B 5~8번」), 같은 이름이 두 체계를 가리키는 것을 막기 위해 **2026-09-10에 연구자가 확정했다** — **연구 진행 체계는 「단계 A~G」, 원전 확보 구역은 「목록 A·목록 B」.** 🔴 **앞으로 `Header A/B`라는 표현은 쓰지 않는다.** 기존 문서에 남은 「헤더 A·B」는 정비 시 「목록 A·목록 B」로 바꾸며, **정비는 연구판정과 분리한다.**
> 📌 **이전 단계(backbone 탐색)의 작업지시서는 `17-backbone-model-search`이고 이력으로 보존한다.**
> ⚠️ 이 지도는 다음 스레드에서도 재공유된다.

## 목적

지금부터는 원전을 더 넓게 수집하는 단계가 아니라, Stage 2에서 검증한 backbone 후보를 동일 기준으로 비교·탈락시키고, 생존한 기존 모형을 기준선으로 Human-AI 협업에서 무엇이 유지·변화·대체·추가되는지를 원전으로 확인하여 석사논문 수준의 연구모형을 조립한다.

## 상위 연구범위

> **「AI 협업 자체를 연구하려는 것이 아니다. Human-AI 협업이라는 새로운 생산조건에서 '개인의 성과'를 어떻게 이해할 수 있는지를 연구한다.」**

이 문장은 연구범위의 렌즈이며 **최종 연구질문·DV·모형을 미리 확정하는 문장이 아니다.**

## 작업 원칙

1. 순서는 **A→B→C→D→E→F→G**. 🔴 **AI 요인이 baseline을 고르게 하지 않는다.**
2. 단계 A에서는 **원칙 1 성과 직접성 → 원칙 2 모형 명확성 → 원칙 3 측정 계승성** 순으로 판정한다. 🔴 **원칙 4는 아직 판정하지 않는다.**
3. 「흥미로운 연구」가 아니라 **「이 연구 위에 실제로 올라설 수 있는가」**를 본다. 계승 대상은 **theory → variable → hypothesis → manipulation/measurement → analysis**이다.
4. Human-Human은 중요한 baseline 문헌군이지만 전체 범위가 아니다. **협업적 업무환경에서 개인성과를 이해·판단하는 기존 검증모형**이 기준이다.
5. Human-AI 단계에서는 결과를 미리 정하지 않는다. 기존 메커니즘이 **유지/약화/대체/추가** 중 무엇인지 **원전이 지지하는 범위에서만** 분류한다.
6. 🔴 **self-efficacy · fairness · trust · contribution ambiguity · identifiability · ownership · authorship 등은 선택된 변수가 아니다.** 원전 근거 없이 승격하지 않는다.
7. 🔴 **새 construct·새 척도는 가능한 한 피한다.** 교수 지침에 맞춰 **기존에 검증된 이론·변수·측정방법의 조합**을 우선한다.
8. 🔴 **「기존 연구가 설명하지 못했다 / 전제가 무너졌다」식의 gap 만들기 금지.** 선행연구가 설명한 영역의 경계를 확인하고 **우리 질문과 같은지 다른지만** 판정한다.
9. **Original verified / metadata-search level / inference를 분리한다.** 원전에 없는 내용을 메우지 않는다.
10. 약어는 첫 사용 시 **한국어명 + English full name + abbreviation**을 쓴다. 저널 약어도 동일하다.
11. 🔴 **각 단계가 끝날 때 결과를 내고 멈춘다.** 다음 단계로 자동 진행하지 않는다.

## 단계 A — 첫 작업

**A-3** Kacmar 등 (2003), **A-1** Duarte 등 (1994), **C-1** Liden & Mitchell (1983), **B-1** Karau & Williams (1993)을 **Stage 2에서 확인한 원전 증거만으로** 다시 비교한다.

### 반드시 분리할 항목

| |
|---|
| **원칙 1** — Y가 개인성과의 이해/판단에 얼마나 **직접** 연결되는가 |
| **원칙 2** — 검증된 관계가 얼마나 명확하고 강한가. **유의/비유의 · 반복검증 · 단순 해석과 실제 검증**을 분리 |
| **원칙 3** — theory → variable → hypothesis → manipulation/measurement → analysis 중 **실제로 무엇을 계승할 수 있는가** |
| 🔴 **방법의 매력과 효과의 강도를 섞지 않는다** |

### 후보별로 미리 분리해 둔 것

| 후보 | |
|---|---|
| **A-3** | 모형은 강하지만 **LMX·소통빈도·성과평정 세 척도 모두 현재 🟡** (`20-` §5) |
| **C-1** | 조작·도구 계승성은 강하지만 **전체 성과평정 효과 t = 1.44 비유의** |
| **A-1** | 객관성과-평정 관계는 직접적이나 **객관성과 자료 재현비용이 큼** |
| **B-1** | **Y가 개인 성과평정이 아니라 effort**이며, **보조이론/실험논리 가능성과 backbone 적합성을 구분** |

🔴 **단계 B의 이론복원이나 Human-AI 원칙 4 탐색은 아직 하지 않는다.**

### 단계 A 산출 형식

1. 4개 후보 × 원칙 1~3 비교표
2. 후보별 **「살아 있는 장점 / 치명적 또는 실질적 약점」**
3. **생존 / 보류 / 탈락** 판정
4. 생존 후보가 2개면, 단계 B에서 무엇을 추가 확인해야 최종 1개를 고를 수 있는지
5. 미확인 항목은 **⬜로 유지**
6. 🔴 **문서 결함·서지 정비는 연구판정과 별도 섹션으로 분리**

### 🔴 판정 이력을 보이게 한다 — 2026-09-10 연구자 지시

`19-` §6에 이미 원칙 1~3 비교표가 있다. **그것은 당시 evidence state에서의 판정으로 보존하고 고치지 않는다.** 단계 A의 재판정은 **`22-stageA-backbone-rejudgment`에 새로 작성**하며, **왜 판정이 달라졌는지를 작업 ①·②의 추가 원전검증 결과와 연결한다.**

```

```
