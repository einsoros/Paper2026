# 연구 문제 및 목적

◆ 인간-AI 공동 생성물의 귀속을 다룬 연구는 **「AI에게 얼마의 크레딧을 부여할 것인가」**라는 배분 판단을 질문으로 삼아 왔으나,
　<u>그 귀속의 어려움이 **실제 성과평가 절차의 공정성 지각**에 미치는 영향은 검증되지 않았다</u>
　(He et al., 2025; Orlikowski, 2007; Leonardi, 2011)

◆ 불확실성 관리 이론은 불확실성이 현저할 때 공정성 판단이 흔들린다는 것을 보였으나,
　<u>그 불확실성을 **조직 안에서 수행되는 업무의 성격**에서 찾은 연구는 확인되지 않는다</u>
　— 검토한 5편이 전수 불확실성을 **조작이거나 외부 상황**으로 처리한다
　(Van den Bos, 2001; Lind & Van den Bos, 2002)

➡ 이에 본 연구는 **귀인이론의 기대원리**와 **Leventhal(1980)의 절차 규칙**을 기반으로,
성과 기여 귀속 모호성이 **지각된 평가 불확실성**을 거쳐 절차공정성 지각으로 이어지는 경로를 시나리오 실험으로 규명하고자 한다

# 이론적 배경 — 이론은 두 개다

| ① 귀인이론 · 기대원리 (Weiner, 1985) | ② 절차 규칙 (Leventhal, 1980) |
|---|---|
| 원인을 안정적으로 귀속할 수 있을 때 미래 결과를 예측할 수 있다 | 절차공정성은 **일관성(consistency)**과 **정확성(accuracy)** 규칙의 충족으로 판단된다 |
| **귀속할 수 없으면 예측할 수 없다** | 예측할 수 없는 평가는 **그 규칙이 지켜졌다고 판단할 근거를 잃는다** |
| → **H1 (IV → MV)** | → **H2 (MV → DV)** |

> **기여를 가릴 수 없으면 평가를 예측할 수 없고,
> 예측할 수 없는 평가는 일관되고 정확하다고 판단할 근거를 잃는다.**

# 연구 모형 및 가설

```
                  ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
                     MOD 평가 절차 명확성
                  └ ─ ─ ─┬─ ─ ─ ─ ─┬─ ─ ┘
                    (a안) ⋮   (b안) ⋮
                          ▼         ▼
   IV ──────────────▶  MV  ──────────────▶  DV
 귀속 모호성          평가 불확실성        절차공정성 지각
 (조작·무작위 배정)      (측정)               (측정)
   └───────────── H3 매개 (간접효과) ─────────────┘
```

| | 가설 | 근거 |
|---|---|---|
| **H1** | 귀속 모호성이 높을수록 지각된 평가 불확실성이 높아질 것이다 | 귀인이론 기대원리 |
| **H2** | 지각된 평가 불확실성이 높을수록 절차공정성 지각이 낮아질 것이다 | Leventhal 절차 규칙 |
| **H3** | 귀속 모호성이 절차공정성 지각에 미치는 영향은 평가 불확실성에 의해 매개될 것이다 | H1 + H2 연쇄 |
| **H4** | 평가 절차 명확성은 그 경로를 조절할 것이다 | ⚠️ **조절 위치 검토 중** |

# 분석 계획

```
① 조작 점검         독립표본 t검정 — 두 조건이 실제로 다르게 지각됐는가
② 신뢰도 · 타당도    Cronbach's α · EFA/CFA · 판별타당도(AVE, HTMT)
③ 공통방법편의       Harman / marker variable
④ H1               집단 간 평균차 (t검정)
⑤ H2 · H3          PROCESS Model 4 + 부트스트래핑 5,000회 · 95% CI
⑥ H4               조절된 매개 — 상호작용항 + 조건부 간접효과
```

**무엇을 보고 무엇이라 말할 것인가**

> H3의 간접효과는 **두 계단의 계수를 곱한 값**이다.
> 귀속이 모호할수록 평가를 예측하기 어려워지고, 예측하기 어려울수록 절차가 공정하다고 보기 어려워진다.
> **두 계단 중 하나라도 끊기면 곱이 0이 되므로, 그 숫자 하나가 「경로 전체가 실제로 이어져 있는가」를 요약한다.**

# 한계 및 향후 계획

**설계상 알려진 한계 — 감추지 않고 명시한다**

| | |
|---|---|
| **a경로** IV → MV | IV가 **무작위 배정 조작**이므로 응답자 특성과 무관하다 |
| **b경로** MV → DV | 매개변수는 무작위 배정할 수 없다. **순차적 무시가능성 가정**에 의존하며 이는 실험적 매개분석의 표준적 한계다 → 통제변수 4개 투입 + 한계 명시 |
| **시나리오** | 가상 상황이므로 실제 평가 맥락에 대한 외적 타당도에 제약이 있다 |
| **단일 시점** | MV·DV를 같은 응답자가 자기보고 → 공통방법편의 점검으로 대응 |

**향후 계획** ⬜ 9월 초 문항 확정 → 9월 중순 조사 → 9월 말 분석 → 10월 본문 → 12월 초 파이널 디펜스

**남은 논의 사항** ⬜ ① 조절 위치 ② MOD 문항 조달 ③ DV 측면 선언 ④ 표본 규모
