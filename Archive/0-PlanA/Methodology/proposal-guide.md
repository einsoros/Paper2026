## 1. 01 연구배경 — 깔때기 구조

**패턴**: 불릿 5~6개. 각 줄이 **선행연구 1건 + 출처**. 뒤로 갈수록 좁아진다.

```
① 이 분야가 왜 어려운가            (Hall & Hofer 1993)
② 판단에 편차가 있다                (Sharma 2015)
③ 그 편차에 개인 특성이 관여한다      (Franke et al. 2008)
④ 기준은 5범주로 정리된다            (구중회 외 2019)
⑤ 그중 하나가 가장 결정적이다        (MacMillan 1985; Gompers 2020)
⑥ 그런데 그 안에서 편차가 크고, 본인도 모른다  (Zacharakis & Meyer 1998)
```

**⑥이 다음 장의 문제의식으로 연결된다.** 배경의 마지막 줄은 반드시 **문제의 씨앗**이어야 한다.

⚠️ **주의**: 배경에서 인용한 문헌이 **자기 방법론을 반박하지 않는지** 확인할 것. (동기 자료에서 실제로 발생 — 아래 §9 참조)

## 2. 02 문제의식 — **한 줄 프레임이 핵심**

**패턴**: 제목 아래 **표어 한 줄**을 굵게 놓는다.

> 예: **"평가 '객체'에서 평가 '주체'로의 시각 전환"**

이 한 줄이 발표 전체를 지탱한다. 심사위원이 기억하는 것도 이것이다.

**본문 3단**
1. 기존 연구가 무엇을 밝혔는가 (출처 나열)
2. **그런데 무엇을 다루지 않았는가** — 가장 가까운 선행연구를 지목해 한계를 명시
3. 본 연구는 그 공백에 주목한다 → **한 문장으로 연구 구조 예고**

**가장 가까운 선행연구를 반드시 지목한다.** 동기 자료는 백지연 외(2022)를 지목하고 *"① 어떤 경험적 원천에서 비롯되는지 ② 어떤 심리적 기제를 통해 판단에 이르는지 규명하지 못했다"*로 공백을 두 갈래로 쪼갰다. **①이 IV, ②가 매개변수에 대응한다.** 공백의 구조가 연구모델의 구조와 일치해야 한다.

---

## 3. 03 연구목적 — 목적 3가지

**패턴**: 02를 한 번 더 정리한 뒤 **목적을 셋으로 번호 매김**.

동기 자료의 3목적 구조가 좋은 본보기다.

| # | 성격 |
|---|---|
| 첫째 | **탐색 → 확인**. 선행연구가 시사한 관계를 이론 기반 확인적 가설로 정식화 |
| 둘째 | **현상 → 기제**. 매개 변수를 실증해 연구 단계를 진전 |
| 셋째 | **이론의 새 맥락 적용**. 기존 구성개념을 새 직무·상황에 적용 |

> 이 3단은 대부분의 매개모형 연구에 그대로 적용된다. **"무엇을 정식화하고 / 어떤 기제를 밝히고 / 어디에 적용하는가"**.

여기서 **종속변수의 범위를 왜 그렇게 좁혔는지**도 밝힌다. 동기 자료는 *"투자기준 5범주 중 가장 결정적 요소로 보고된 창업자 차원에 초점"*으로 축소를 정당화했다.

## 4. 04 연구모델 — 도식 + 가설표

**패턴**: 왼쪽에 경로 도식, 오른쪽에 가설표.

**가설표 형식**

| 구분 | 가설 |
|---|---|
| H1 | IV → MV |
| H2 | MV → DV (하위가설 있으면 H2-1…) |
| H3 | 매개 |

⚠️ **하위가설을 나눌 때 방향을 전부 같게 두지 말 것.** 이론적으로 방향이 갈리는 항목이 있으면 그것만 따로 논증하거나 탐색적으로 표기한다.

⚠️ **조절변수가 있으면 조절 위치(어느 경로를 조절하는지)를 도식에 명시**한다. PROCESS Model 번호도 함께.

---

## 5. 05 이론적 배경 — **경로 배정이 핵심**

**패턴**: 이론 3개 내외, 각 줄 끝에 **어느 경로의 근거인지** 괄호로 명시.

```
사회인지이론·자기효능감 (Bandura 1977·1997)  → (IV > MED 근거)
인적자본 이론 (Becker 1964)                 → (IV 및 DV의 이론적 토대)
(보조) 평가자 자기효능감 (Bernardin 2005)    → (MED > DV 근거)
```

**이 괄호가 이 장의 전부다.** 이론을 나열만 하면 *"그래서 어느 가설의 근거인가"*가 나온다. **경로마다 담당 이론이 있어야 하고, 담당 없는 경로가 있으면 그게 취약점이다.**

> 「(보조)」 표기도 유용하다. 근거 강도가 약한 이론을 정직하게 구분한다.

## 6. 06 연구방법 — 표 하나 + 개요

**표 형식** (동기 자료 그대로 쓸 만함)

| 구분 | 변수 | 정의 | 측정방법 | 참고문헌 |
|---|---|---|---|---|
| 독립변수 | | 한 문장 정의 | 몇 문항·몇 점 척도·원척도명 | 원전 |
| 매개변수 | | | | |
| 종속변수 | | | | |

**개요 4항목**: 대상자 / 문항수 / 설문방법 / 샘플수

⚠️ **실험 설계(시나리오)라면 여기에 추가**
- 설계 구조 (요인 수 × 조건 수, between/within)
- **조작 대상과 통제 대상**
- 조작 점검(MC) 문항
- 무선배정 방식

## 7. 07 향후 연구계획 — 타임라인

**패턴**: 날짜 구간별 한 줄. 동기 자료 기준으로 프로포절 심사가 8월 말이면:

```
8/26      논문 프로포절 심사
~9월 초    설문문항 확정
~9월 중순   설문조사 진행
~9월 말    데이터 분석
~10월 중순  결과 기준 본문 작성
~10월 말   공헌·시사점·한계 작성
~11월 중순  결론·참고문헌
12월 초    파이널 디펜스
1월       수정·보완 → 최종 논문
```

**이 일정이 사실상 학위 일정의 표준**이다. 본 연구도 같은 틀에 맞추되 **시나리오 실험은 사전검사(pilot)가 추가**된다.

## 8. 발표자료 작성 원칙

| | |
|---|---|
| **장당 한 가지** | 한 장에 두 가지를 넣지 않는다 |
| **출처를 문장 끝에** | 모든 주장에 (저자, 연도). 프로포절에서 출처 없는 문장은 지적 대상 |
| **한 줄 프레임** | 02에 표어 한 줄. 발표의 축 |
| **공백의 구조 = 모델의 구조** | 공백을 두 갈래로 쪼갰으면 모델도 두 경로 |
| **경로마다 이론 배정** | 담당 없는 경로 = 취약점 |
| **축소를 정당화** | 왜 이 범위로 좁혔는지 03에서 밝힌다 |
| **미확정은 미확정으로** | 정하지 않은 것을 정한 척하지 않는다. 프로포절은 **묻는 자리**다 |

## 9. 자기 점검 — 심사에서 나오는 질문

작성 후 아래를 스스로 통과시킨다.

| # | 질문 | 어디서 답하나 |
|---|---|---|
| 1 | 가장 가까운 선행연구는 무엇이고 무엇이 다른가 | 02 |
| 2 | 왜 이 변수를 매개로 두었나 | 05 경로 배정 |
| 3 | **IV와 매개변수가 같은 걸 재는 것 아닌가** | 06 판별타당도 |
| 4 | 측정 방법이 구성개념 정의와 맞는가 | 06 |
| 5 | **배경에서 인용한 문헌이 내 방법론을 반박하지 않는가** ★ | 01 ↔ 06 대조 |
| 6 | 표본 확보가 현실적인가 | 06 |
| 7 | 결과가 예측과 다르면 어떻게 되나 | 준비만 (`analysis-plan` §5) |
| 8 | 통제변수는 무엇인가 | 06 |

> **5번이 특히 자주 놓친다.** 배경에서 *"응답자는 자기 판단 과정을 잘 모른다"*를 인용하고 방법에서 자기보고 설문을 쓰면 자기모순이 된다. 01을 다 쓴 뒤 06과 나란히 놓고 대조할 것.
