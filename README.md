## 연구 개요

생성형 AI에 대한 **의존적 인지위임**이 근로자의 **수행가능성 판단**과 갖는 관계를 검토한다.

```
DCO  의존적 인지위임 ── H1(−) ──→ SAC   독립수행 자신감
                     └─ RQ1(?) ─→ RBSE  역할확장 자기효능감
```

매개 · 조절 없음. SAC→RBSE 경로 없음. 횡단 설문. 핵심 측정 18문항.

## 진행 상태

번역 · 사전검토 완료 → **설문지 동결** → 리서치 업체 견적 문의 → 본조사 → 분석 → 집필

상세는 `PlanW/00_Master/PlanW_Current_State.md`.
