# Zotero Workflow

Use Zotero for the bibliography layer.

## Minimal Setup

1. Decide whether Zotero Sync is needed.
2. Create a Zotero collection for this project.
3. Add papers by DOI, arXiv ID, URL, or PDF import.
4. Check title, authors, year, venue, DOI, and URL.
5. Use stable citation keys through Better BibTeX.
6. Import or link paper notes into Obsidian.
7. Export BibTeX or Better BibTeX into `Writing/latex/references.bib`.

Detailed setup checklist: [Zotero-Obsidian Setup](../Workflow/zotero-obsidian-setup.md)

## Citation Key Rule

Use one citation key consistently across:

- Zotero item
- paper note front matter
- feature matrix
- LaTeX citation

Example:

```text
smith2024method
```

## Metadata Checklist

- [ ] Title is correct
- [ ] Authors are correct
- [ ] Year is correct
- [ ] Venue is correct
- [ ] DOI or arXiv ID is present
- [ ] PDF is attached where possible
- [ ] Citation key is stable
