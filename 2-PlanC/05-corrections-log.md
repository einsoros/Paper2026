## C-1 · Weiner를 원래 자리에 놓으면 확장 부담이 사라진다

| | |
|---|---|
| 주장 | (b)로 놓으면 귀인이론이 **확장이 아니라 원래 용법**이 되어 논증 부담이 사라진다 |
| 🔴 정정 | **검증 전이다.** 「AI인가 나인가 판별 불가」가 귀인이론의 **locus ambiguity라는 확립된 상태**인지, 아니면 locus attribution과 **다른 새 상태**인지 확인해야 한다. 섞으면 같은 문제가 반복된다 |
| 유형 | ⑤를 ①로 |

## C-2 · 기여 모호성 → 자기효능감 저하

| | |
|---|---|
| 주장 | 「AI를 회수하면 유지 가능한가」는 자기효능감 문헌의 언어 그대로다 |
| 🔴 정정 | **화살표를 만들면 안 된다.** AI-independent self-efficacy가 **선행인지 결과인지**, attribution과 어떤 관계인지 미확인 |
| 유형 | ⑤를 ③으로 |

## C-3 · Pan이 08-23의 최대 부담을 없앴다

| | |
|---|---|
| 주장 | 사회물질성+귀인이론 조합이 정식화됐으므로 **확장 논증을 안 해도 된다** |
| 🔴 정정 | **너무 강하다.** Pan이 줄여주는 것은 「AI 맥락에 귀인이론을 적용해도 되는가」라는 **일반적 부담**뿐이다. **「AI 공동생산 → 자기 기여 귀속 모호성」이라는 핵심 화살표는 정당화해주지 않는다.** Pan은 AI-in-appraisal, 우리는 AI-in-production |
| 유형 | ④를 ③으로 |

## C-4 · 선행논문의 후속 과제 언급이 우리 자리의 공식성을 정한다

| | |
|---|---|
| 🔴 정정 | **틀렸다.** 연구공백은 선행논문의 future research 문장으로 **허가받아 생기는 것이 아니다.** 기존 연구가 무엇을 설명하고 무엇을 설명하지 않는지를 **우리가 논증**하면 된다 |
| 유형 | 연구자의 자리를 남에게 넘긴 것 |

📌 **이것이 가장 나쁜 오류였다.**

## C-5 · 저널 위상을 근거로 쓴 것

| | |
|---|---|
| 🔴 정정 | **저널 위상은 construct validity나 화살표를 대신하지 않는다.** 「HRM 최상위 저널」은 연구모형 판단에 도움이 안 된다 |

## C-6 · Vest에 관찰가능성 → 평가지각 → 보상신념 연쇄가 있다

| | |
|---|---|
| 🔴 정정 | **철회.** Vest 등(1995)은 상사의 성과 지식 · 지각된 평가 정확성 · 상사 평가행동을 **구별된 구성개념**으로 측정하고 **각각을 별도의 위계적 회귀**에서 도구성 신념의 예측변수로 넣었다. **순차적 인과나 매개경로는 검증하지 않았다.** 평가 사용 지각이 그 관계들을 조절한다 |
| ⚠️ | **리포에 이미 정확히 적혀 있었는데** 그 줄을 인용해 놓고 다음 문단에서 화살표로 그렸다 |
| 유형 | ③을 왜곡 |

## C-7 · Vest 문항의 암묵적 전제를 발견했다

| | |
|---|---|
| 주장 | 「평가가 내가 수행했다고 느낀 것과 일치했다」는 문항은 **「내가 느낀 기여」가 확정돼 있다고 전제**하는데, 우리 현상은 그 전제가 무너진 상태다 |
| ⚠️ 정정 | **좋은 문제제기이지만 학술적 기여로 선언할 단계가 아니다.** 문항 전체와 construct 정의를 원문으로 봐야 하고, 특히 그 문항이 **기여도(contribution share)**를 뜻하는지 **자기 성과수준(self-assessed performance)**을 뜻하는지 구별해야 한다. 후자면 인접하지만 동일하지 않다 |
| 유형 | ⑤를 ①로 (미완) |

## C-8 · 「분배공정성이면 설문이 거의 강제」

| | |
|---|---|
| 🔴 정정 | **과했다.** 시나리오 설계도 성립한다. 판단 근거는 측정 가능성이 아니라 **척도의 사후형 성격과 실무 시사점**이었다 |

## C-9 · 「문항이 적을수록 변량 제약에 취약하다」

| | |
|---|---|
| 🔴 정정 | **틀린 문장이다.** 바닥·천장효과는 **문항 내용·응답척도·표본 특성**에서 나오지 문항 수에서 나오지 않는다. 2문항의 실제 문제는 **내용영역 포괄 · 측정오차 추정 안정성 · 판별타당도 방어력**이다 |
| 유형 | 통계적 사실 오류 |
