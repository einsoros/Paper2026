# Ⅰ. A-3 — 「The Interactive Effect of Leader–Member Exchange and Communication Frequency on Performance Ratings」

**Kacmar, K. M., Witt, L. A., Zivnuska, S., & Gully, S. M. (2003). *JAP* 88(4), 764–772.** 🟢🟢 A

## ① 실제 검증관계 — 공통 구조 + Study별 구현

> 🔴 **「동일 construct가 완전히 반복검증되었다」고 쓰지 않는다.** 같은 개념적 상호작용 구조가 **서로 다른 operationalization에서 두 번 검증**되었다(`19-` §4-12 · 2026-09-10 연구자 지시).

**공통 검증구조** `[원전확인]` ③
> **LMX × 소통 빈도 → 상사평정 직무성과**의 **상호작용.** 가설은 한 문장뿐이다 — 「소통 빈도가 LMX 품질–직무성과 평정 관계를 조절하여, 상사와 자주 상호작용하는 근로자에게서 LMX 품질이 평정과 더 강하게 관련된다」. **M(매개)은 없다.**

**형태도 두 연구에서 유사하다** ③ — 고LMX에서는 자주 소통한 근로자가 가장 유리하고 드물게 소통한 근로자가 가장 불리하다. **저LMX에서는 반대**로 드물게 소통이 가장 유리하고 자주 소통이 가장 불리하다.

| | **Study 1** | **Study 2**(constructive replication) |
|---|---|---|
| **표본** | 유통서비스. 부하 완비 **188명**(초대 310 → 254 참여), 일선 감독자 **16명**(19명 중). 같은 상사 아래 **사실상 동일한 역할**(분류·포장·배송·운반) | 주정부 세무징수기관. 관리자 **59명**(65명 중), 부하 완비 **153명**(325 → 203 사용 가능). 평균 관할 6.7명 |
| **X · LMX** | 7문항(Scandura, Graen & Novak 1986), 7점(strongly disagree~agree), **α = .87** | 동일 척도, **α = .83** |
| **Z · 소통 빈도** | **McAllister(1995) 4문항**, **7점**(1 = 지난 6개월간 한두 번 ~ 7 = 하루에 여러 번), **α = .85** | 🔴 **이 연구를 위해 개발한 8문항**(부록 전문), **5점**(1 = 한 달 한 번 미만 ~ 5 = 하루 한 번 이상), **α = .84**. 문항은 **채널별 접촉**(메모·대면 대화·이메일·전화의 송신/수신) |
| **Y · 성과평정** | **직무 전용 자작 5문항**, **α = .91**. 앵커가 **상대 순위**다 — (a) 약함/하위 10% ~ (e) 최상/상위 10%, 1~5점 | **Wayne & Liden(1995) 5문항**, **α = .91**. **문항마다 척도가 다르다**. ⚠️ 저자 각주: **S1 척도는 표본 1의 직무 전용이어서 S2에 쓸 수 없었다** |
| **r(LMX, 평정)** | **.22\*\*** | **.32\*\*** |
| **r(소통, 평정)** | **.14\*** | **−.03 ns** |
| 🔴 **r(LMX, 소통)** | **.47\*\*** | **.10 ns** |
| **ICC** | .232 | .234 |
| **주효과** | LMX γ = .090, **t = 1.92, p < .10 근접** · 소통 γ = .033, **t = 0.67 ns**. +2.2% | LMX γ = .232, **t = 3.94, p < .01** · 소통 γ = −.089, **t = −.91 ns**. +8.4% |
| **상호작용** | γ = .058, **t = 2.04, p < .05.** **ΔR² +1.7%** | γ = .135, **t = 2.03, p < .05.** **ΔR² +1.4%** |
| **통제** | 3.9%, **조직 재직기간만 유의**(γ = .037, t = 2.39) | 4.1%, **전부 비유의** |

**분석** ③ — **HLM 4모형 순차 추정**(절편만 → +통제 → +주효과 → +상호작용) · 상호작용 형태는 **±1 SD와 평균**에서 도식 · 수준 1 설명분산은 Bryk & Raudenbush(1992) 공식 · **혼합선형모형 병행 확인**에서 결과 거의 동일.

⚠️ **두 수치를 섞어 쓸 수 없다** — Study 2의 **최종 모형 표에서는 소통빈도 계수가 −0.76, t = −2.19\*로 유의**한데, **주효과 모형에서는 비유의**했다(`19-` §4-13).

🔴 **저자 자신이 ΔR²가 비실험 연구 조절효과의 통상 범위(.01~.03) 안에 있다고 적는다.**

## ③ Core / Peripheral / Uncertain 후보

| 등급 | 요소 | 층 | 근거 |
|---|---|---|---|
| **Core** | **X × Z → Y 조절 구조 자체**(M 없음) | ③ | 검증된 것이 이것뿐이다 |
| **Core** | **Y = 상사평정 개인성과 · X와 Z = 부하 자기보고** — 즉 **Y의 출처가 X·Z와 분리** | ② | 두 연구 모두 동일. ⚠️ 다만 X와 Z는 같은 응답자다(공통방법) |
| **Core** | **부하가 상사에 내포된 다수준 자료 구조** | ②③ | 두 연구 모두 ICC ≈ .23이고, 분석 전체가 이 구조 위에 서 있다 |
| **Core** | **가설이 한 문장인 구조** | ①③ | 계승할 가설 언어가 하나다 |
| **Core** | **HLM 4모형 순차 추정 + ±1 SD 도식 + ΔR² 보고** | 분석 | 본문에 절차로 적혀 있다 |
| **Peripheral** | **소통 빈도의 구체적 operationalization**(4문항/7점 vs 8문항/5점) | ② | 🟢 **저자 자신이 두 연구에서 바꿨고 같은 형태를 얻었다.** 바꿀 수 있다는 근거가 원전 안에 있다 |
| **Peripheral** | **성과평정 척도의 구체 문항** | ② | 두 연구가 다르고, **저자 각주가 S1 척도를 S2에 쓸 수 없었다고 밝힌다** |
| **Peripheral** | **통제변인 다섯**(성별·인종·연령 비유사성 · 조직 재직기간 · 상사 직접 보고 기간) | ② | S1에서 조직 재직기간만 유의, S2에서 전부 비유의 |
| **Peripheral** | **표본 산업**(유통서비스 / 세무징수기관) | ② | 두 연구가 다르다 |
| **Uncertain** | 🔴 **LMX 7문항의 실제 문항** | ② | **A-3이 쓴 7점 동의척도 판본의 문항 전문이 ⬜**(`20-` §12). **측정 계승성 세부 미확인 — 단계 F 재개** |
| **Uncertain** | **Z를 「빈도」로 두는 것이 필수인지** | ②④ | 저자가 **소통의 내용·관계적 성격을 측정하지 않았다**고 명시하므로, 빈도가 이론적으로 필수인지 편의인지 **원전만으로 판정 곤란** |
| **Uncertain** | **공통방법 분산의 영향 크기** | ⚠️ | X·Z가 같은 부하 응답자다. 저자가 한계로 적었으나 크기를 추정하지 않았다 |

| |
|---|

# Ⅱ. C-1 — 「THE EFFECTS OF GROUP INTERDEPENDENCE ON SUPERVISOR PERFORMANCE EVALUATIONS」

**Liden, R. C., & Mitchell, T. R. (1983). *Personnel Psychology* 36, 289–299.** 🟢🟢 A · ⬜ 호는 표지에 「1983, 36」만 인쇄

## ① 실제 검증관계

**검증구조** `[원전확인]` ③
> **집단 상호의존성(고/저 2수준, 지시문 조작) → 평정 차이점수 `(A+B)/2 − C`.** **M 없음 · Moderator 없음.** 가설은 한 문장 — 「집단이 고도로 상호의존적일 때 저성과자는 더 높게, 고성과자는 더 낮게 평정된다. 변환점수 평균이 **저**상호의존 조건에서 더 커야 한다」

## ⑤ 개인성과·성과평정을 실제로 어떻게 operationalize했는가 — 두 층으로 분리

> 🔴 **⑤를 하나의 이름으로 정하지 않는다**(2026-09-10 연구자 지시). **「평정 편향」이라고 단정하지 않는다** — 저자가 차이점수를 그렇게 정의했다는 근거가 우리 기록에 없다. ⬜ 원문 재확인 대상.

| 층 | |
|---|---|
| **측정대상** | **supervisor 역 피험자가 각 개인(A/B/C)에게 부여한 성과 관련 평정과 의사결정.** 「선택·배치 책임자」 역할을 부여하고 「이 집단이 계속 함께 일하는 팀이고 여러 인사 과업을 함께 해왔다고 가정해 판단·평정하라」고 지시한다 |
| **구성** | ⓐ 지침 대비 **영역별 차원 평정**(7점, 1/4/7 앵커) → 차원별 평정을 합해 척도 수로 나눔 · ⓑ **전체 성과 1–10** · ⓒ **$1,000 보너스 배분액** · ⓓ 승진추천 · ⓔ 유지 · ⓕ 향후 중요업무 부여 자신감 · ⓖ 향후 밀착감독(**역채점**) · ⓗ 과업 몰입 지각 (ⓓ~ⓗ는 10점) |
| **분석 operationalization** | **`(A+B)/2 − C`** — **동일 평정자 내에서 우수 수행자(A/B)와 저성과자(C)에 대한 평정 차이(differential rating score).** 7종 각각에 대해 산출된다 |

| **측정·조작 계승성** | 🟡 네 척도 중 **자체 개발 8문항만 🟢 부록 전문.** LMX·성과·S1 소통은 🟡. **분석 절차는 🟢🟢**(HLM 4모형·±1 SD·ΔR²). ⬜ **세부 미확인 — 단계 F 재개** | 🟢🟢 **조작문 전문 · 참 성과 구성 · 차이점수 변환 · 7종 문항 · 앵커가 전부 본문에.** 게다가 **1982년 원형에서 같은 도구 확인** |
| **상위 질문과의 직접성** | **판단 쪽 절반에 직접** — 평가자가 쓰는 정보. 🔴 **업무구조는 변수로 들어오지 않는다** | **구조 쪽 절반에 직접** — 업무구조가 판단을 바꾸는가. 🔴 **관계·접촉 정보는 변수로 들어오지 않는다** |
| **Human-AI 이전에 이미 존재하는 원전의 범위** | 다룬 범위는 **현장의 dyadic 상사–부하 관계에서, 관계와 접촉이 결합해 상사평정에 반영되는 정도**까지다. **협업은 표본 특성으로만 존재**하고, **객관 성과·평정 정확성·개인 기여·피평가자 본인의 지각은 이 범위 밖**이다 | 다룬 범위는 **실험실에서 지시문으로 조작된 업무구조가, 상호작용 경험이 없는 제3자 평정자의 개인별 판단·결정에 만드는 차이**까지다. **참 성과는 명확하게 통제**되어 있고, **기여 식별의 곤란·평정 정확성·피평가자 본인의 지각은 이 범위 밖**이다 |

🔴 **마지막 축은 「기존 연구의 한계」가 아니라 「해당 원전이 다룬 범위」의 기술이다.** 두 편은 서로를 보완하거나 대체하지 않고 **다른 절반을 각각 다룬다.**

🔴 **backbone 최종 선택은 하지 않았다.**

# Ⅲ-a. ⭐ 세 층 구분과 두 baseline의 위치 — 2026-09-10 연구자·GPT 판단

> 🔴 **이 절의 세 층 구분은 연구자·GPT의 판단이며 원전에서 온 것이 아니다.** 두 baseline의 위치 배정은 Ⅰ·Ⅱ의 복원 결과에서 나온다.

**A-3도 C-1도 우리가 처음 관찰한 현상 전체를 혼자 설명하지 않는다.** 우리가 보려는 현상에는 적어도 세 층이 섞여 있다.

```
① 성과가 만들어지는 구조  →  ② 개인에 관한 정보가 무엇으로 남는가  →  ③ 평가자가 그 정보로 개인성과를 어떻게 판단하는가
```

| 층 | A-3 | C-1 |
|---|---|---|
| **①** 생산 구조 | 🔴 변수로 들어오지 않는다. 협업은 **표본 특성**으로만 존재(Study 1의 동일 역할) | 🟢 **X로 조작된다**(상호의존성 고/저, 지시문) |
| **②** 남는 정보 | 🟢 **관계 품질(LMX)과 접촉 빈도**가 그 정보로 측정된다 | 🔴 변수로 들어오지 않는다. 정보는 **실험자가 문서로 고정**했다(A·B 우수 / C 부실) |
| **③** 판단 | 🟢 상사평정 직무성과 | 🟢 평정 7종의 평정자 내 차이점수 |
| **다룬 경로** | 주로 **②→③** | 주로 **①→③** |

🔴 **①이 ②를 어떻게 바꾸는가는 두 baseline 어느 쪽에서도 검증된 것이 아니다.** C-1은 ①을 조작하면서 ②를 **고정**했고(참 성과가 명확하고 모호하지 않게 통제됨), A-3은 ②를 측정하면서 ①을 **변수로 두지 않았다.**

⚠️ **이것은 두 원전이 다룬 경로의 기술이며 연구공백 선언이 아니다**(C-22 · `02-working-rules` §2). **문헌이 적다거나 기존 연구가 실패했다는 진술이 아니다.**

📌 **단계 C의 대상이 여기서 정해진다** — 🔴 **「빈칸을 메울 새 construct를 찾는 것이 아니다.」** Human-AI 문헌에서 **A-3 또는 C-1의 기존 구조에 실제로 연결할 수 있는, 이미 검증된 변화요인이 있는지**를 확인하는 것이다.

# Ⅳ. 예비후보 메모 — A-1 「EFFECTS OF DYADIC QUALITY AND DURATION ON PERFORMANCE APPRAISAL」

**Duarte, N. T., Goodson, J. R., & Klich, N. R. (1994). *AMJ* 37(3), 499–521.** 🟢🟢 A · 🟡 **보류**

- **왜 보류인가** — 원칙 1·2는 넷 중 가장 강하다(R² .58/.59/.35, 3원 상호작용이 세 종속변수에서 동일 패턴, 대안설명 배제 검정까지 있음). 막는 것은 **원칙 3의 재현비용**이다 — 객관 성과가 **시간 계측 가능한 정형 직무의 6개월 사내 기록**이다. 여기에 **LMX 리더 폼 문항 미확보**(`20-` §12)가 더해진다.
- **어떤 조건에서 복귀하는가** — **시간 계측 가능한 정형 직무의 객관 성과 자료에 접근할 수 있는 표본이 확보되면** 즉시 복귀한다(`22-` §3).
- **A-3·C-1 모두 치명적 문제가 생기면 무엇을 제공하는가** — **넷 중 유일하게 「평정」과 「평정 대상의 산출」을 모두 측정한 구조**다. 즉 **객관적으로 관찰되는 성과정보와 사회적 맥락정보가 평정에서 어떻게 결합되는가**를 다룰 수 있는 유일한 baseline이다.
- 🔴 **본문 복원 대상이 아니다.** A-3·C-1과 동일한 한 장 복원은 하지 않았다. 🔴 **생존후보로 본문에 재진입시키지 않는다.**
- ⚠️ 인용 시 주의 — r(객관성과, LMX) = **.07 비유의**이고 동시측정이라 인과 불가다. 저자가 「보통 편향이나 왜곡으로 여겨지는 것이 **타당한 인지 과정의 일부일 수 있다**」고 적는다.
