### 11-2-a. ⭕ 가장 강한 직접 증거 — Study 2

> **단계 C의 핵심 질문은 「AI 관련 단서가 ③ 판단을 바꾸는가」다. 그에 가장 깨끗한 직접 증거는 Study 2다.**

**도움 내용을 동일하게 두고 출처만 AI / non-AI / control로 달리했을 때, 대상에 대한 사회적 판단이 달라졌다** — laziness(AI 2.50 vs non-AI 2.16, t(787.5)=3.79, p<.001 · vs 무도움 2.02, t(766.9)=5.55, p<.001) 및 **competence · diligence · independence · self-assuredness**의 차이가 모두 95% CI에서 0을 배제했다. N = 1,203.

### 12-5. Mediation

🟢 **clinical skills가 매개변수로 검정됐다 — 단 종착 Y는 clinical skills가 아니다.**

🔴 **clinical skills는 ⓐ 그 자체로 하나의 Y이면서 ⓑ 다른 두 Y에 대한 매개변수로 쓰였다. 두 역할을 섞어 쓰지 않는다.** 아래 매개모형에서 **clinical skills는 M이고, 종착 Y는 overall healthcare experience와 overall competence 둘**이다. **조건 → clinical skills 자체의 효과는 매개가 아니라 12-4의 직접 비교다.**

```
조건(더미) → clinical skills → ⓐ overall healthcare experience
조건(더미) → clinical skills → ⓑ overall competence
```

🔴 **attributional discounting은 측정·검증되지 않았다.** 전편에서 **1회**, **Discussion의 해석**이다 — 「관찰자는 attributional discounting을 적용해, 그 의사의 성공을 **AI 도구에 더** 돌리고 **의사의 실제 능력에는 덜** 돌릴 수 있다(ref 21)」. 🔴 **construct로 측정된 적이 없다. Discussion 해석과 검증된 매개(clinical skills)를 절대 섞지 않는다.**

### 13-4. 🔴 attribution / ownership 구분 — 저자 정의 원문

> **「Attribution is the visible recognition provided to the author of a work.」** — 저작물의 저자에게 주어지는 **가시적 인정**이다.
>
> **「Attribution differs from ownership in two key ways.」** ⓐ **법적으로** ownership은 특정 권리와 책임을 부여한다(더 이상 유통되지 않는 저작물을 되살릴 수 있는 것 등). ⓑ **심리적으로** ownership은 **「대상에 대한 소유감(sense of possession over the target)」**을 뜻한다. **「두 경우 모두 ownership이 attribution을 요구하지는 않는다.」**

| 🔴 |
|---|
| 🔴 **attribution을 「내 기여를 식별할 수 있는가」로 해석하면 안 된다** — 저자 정의는 **저자에게 주어지는 가시적 인정**이다. `identifiab`는 전편 **1회**뿐이다 |
| 🔴 **ownership을 contribution과 동일시하면 안 된다** — 저자가 둘을 명시적으로 갈랐고, ownership은 이 논문의 **선행연구 검토 대상**이며 **측정된 Y가 아니다** |

### 16-4. ⭐⭐ 「inflation」의 정확한 의미

🔴 **저자는 rating–performance discrepancy를 직접 산출하지 않았다.**

| | 결과 |
|---|---|
| **Study 2 Table 1 Model 2** | 🔴 **robot usage → 성과평정 직접효과 b = 0.09, SE = 0.12, t = 0.81 — 비유의** |
| | 🟢 IPT → 성과평정 **b = 0.45, SE = .08, t = 6.00\*\*\*** |
| | 🟢 간접효과(RMediation) **0.52, SE = 0.13, 95% CI [0.33, 0.74]** |
| **Study 3** | 🟢 IPT → 성과평정 **β₁₂ = 0.40, SE = .09, CV [0.232, 0.571]** · 간접효과 **0.06, SE = .04, p = .024, CV [0.001, 0.146]** · H1 랜덤기울기 절편 **γ₁₀ = 0.16, SE = .08, p = .024, CV [0.002, 0.330]** |

⭕ **따라서 검증된 것은 「상사가 로봇 사용자를 더 높게 평정한다」가 아니라 「로봇 성과를 직원에게 귀속시키는 상사가 그 직원을 더 높게 평정한다」다.** 제목과 초록의 「in turn inflates」는 **간접경로의 요약**이며 총효과가 유의했다는 뜻이 아니다.

「illusory」의 근거는 두 겹이다 — ⓐ **실험에서 성과·노력 정보를 조건 간 동일하게 제시한 뒤 IPT가 달라졌고** ⓑ 개념적으로 「**노력이 성과 기여로 비례적으로 전환되지 않기 때문**」이다.
