## 1. 🔴 다섯 층 구분 — 이 프로젝트의 1번 규칙

문헌을 읽을 때 다음을 **섞지 않는다.**

| # | 층 | 무엇 |
|---|---|---|
| **①** | **정의** | 논문이 실제로 **정의한** construct |
| **②** | **측정** | 논문이 실제로 **측정한** construct |
| **③** | **검증** | 논문이 실제로 **검증한** 관계 |
| **④** | **해석** | 저자가 **discussion에서 해석한** 것 |
| **⑤** | **추론** | **우리가 적용하면서 새로 추론하는** 것 |

🔴 **⑤를 ①~④인 것처럼 쓰면 안 된다.**

⚠️ 실제 발생한 오류가 전부 이 규칙 위반이다 — 저자 귀속 오류, 척도 문항수 오독, **construct 정의와 그 결과·설명을 동일시**, **인접 construct를 동일 construct로 취급**, **병렬 예측변수를 연쇄 매개로 서술**.

📌 특히 ①과 ④의 혼동이 잦다. 「저자가 관련연구에서 그렇게 말했다」는 ④이고 검증된 construct가 아니다.

### 🔴 추가 유형 — 2차 인용을 원저자 정의로 쓰는 것

**다른 논문이 옮긴 정의를 원저자의 정의로 쓰지 않는다.**

⚠️ 후속 논문이 어떤 원전의 정의를 재진술하면 **「그 원전이 그렇게 말했다」고 쓰지 않고, 해당 후속 논문의 정의·정리로 기록한다.**

📌 2026-09-07에 Campbell (1990)의 정의를 백과 항목과 2차 자료에서 옮겨 적은 사례가 있다. **폐기했다.**

## 2. 🔴 목적은 critique가 아니라 differentiation / positioning

### ❌ 원칙적으로 피하는 표현

| |
|---|
| 기존 연구는 **실패했다** |
| 기존 연구는 **해결하지 못했다** |
| 기존 접근은 **작동하지 않는다** |
| 기존 연구의 **전제가 잘못됐다** |
| 기존 연구의 **한계는 ○○다** |

🔴 **원저자가 직접 그렇게 규정했거나, 비교 가능한 직접 증거가 있을 때만 사용한다.**

### 🔴 함축 표현도 쓰지 않는다

| ❌ | 왜 |
|---|---|
| **우회로(workaround)** | 「정면 해결 실패」를 함축 |
| **작동을 멈추는 조건** | 실패를 전제 |
| **무력해진다 · 흔들린다** | 동일 |
| 「저자가 그 분석을 하지 않았다」를 **태만처럼 서술** | 연구 범위 선택을 결함으로 읽음 |
| **AI 사용은 능력 신호를 왜곡한다** | 일반화 |
| **평가자가 AI 사용자를 부당하게 감점한다** | 규범적 표현 |

⭕ **중립 표현으로 바꾼다** — 「기존 개인평가에서 특정 정보가 개인판단에 사용될 수 있었던 조건과 정보적 의미가 Human-AI 생산구조에서도 동일하게 유지되는가」

### 각 선행연구에 대해 구분하는 다섯

| # | |
|---|---|
| **1** | 그 연구가 실제로 **무엇을 설명했는가** |
| **2** | 어떤 **대상 / 관계 / 조건 / 수준**을 다뤘는가 |
| **3** | 우리의 최초 문제와 **어디에서 연결되는가** |
| **4** | **어디에서는 동일하지 않은가** |
| **5** | 그 차이가 **이미 다른 문헌에서 설명되어 있는지**, 아니면 **별도의 설명이 필요한지** |

### ⭐ 문장 형식

> **선행연구 A는 X를 설명한다.**
> **현재 우리의 관심은 Y이다.**
> **X와 Y는 Z 지점에서는 연결되지만 W 지점에서는 동일하지 않다.**
> **따라서 Y가 기존 설명의 적용범위 안에 있는지, 또는 별도의 설명이 필요한지를 확인한다.**

### 📌 저자들이 스스로 범위를 적어두었다

| 문헌 | 저자 자신의 범위·미결 진술 |
|---|---|
| **Alchian & Demsetz (1972)** | 전문·예술 노동에서는 활동 관찰이 좋은 단서가 아니며, 그 영역에는 재량 확대·이익분배·파트너십이 쓰인다 (p.786) |
| **Rothstein (1990)** | 정확성이 아니라 신뢰도를 다루었다. 진점수를 알 수 없기 때문이다 (p.327) |
| **Latham & Wexley (1977)** | 접촉량에 따른 도구 선택은 향후 연구가 판단해야 한다 (p.268) |
| **Uribe 등 (2022)** | 직접 관찰이 어려운 세팅에서 효과가 클 수 있고, 상호의존성이 낮으면 덜 중요할 수 있다 |
| **Yang 등 (2025)** | 측정도구 개발·타당화를 사전에 수행할 기회가 없었고, 측정 한계로 다룬다 |

⭕ **우리가 「한계」로 지목할 필요가 없다. 저자들이 그은 선 옆에 우리 현상을 놓아보는 것이 우리 작업이다.**

## 3. 🔴 I→θ를 단일 화살표로 자동 해석하지 않는다

**최소한 다음 다섯 관계를 구분한다.**

| # | 관계 |
|---|---|
| **1** | **information formation / observability** |
| **2** | **information → evaluator judgment** |
| **3** | **observed information → researcher-estimated latent target** |
| **4** | **evaluator judgment → underlying target accuracy / validity** |
| **5** | **rating reliability 등 measurement property** |

🔴 **한 문헌이 이 중 하나를 검증했다고 해서 나머지 관계까지 검증된 것으로 해석하지 않는다.**

⚠️ **이 다섯이 완전한 목록도 아니다.** **개인 target이 없는 연구**(Steyvers 등 2022)는 다섯 어디에도 정확히 들어가지 않는다.

### 🔴 H를 두 칸으로 분리한다

| 칸 | 내용 |
|---|---|
| **H-A** | **Work / production structure** |
| **H-B** | **Evaluation / inference / research structure** |

📌 production structure, work structure, evaluation design, research design, contracting structure가 한 칸에 섞이면 **「생산구조 변화」와 「평가정보 구조 변화」를 혼동한다.**

⚠️ **어느 한쪽이 핵심 분석대상이 아닌 문헌도 있다** — Rothstein은 H-B만, Alchian & Demsetz는 H-A가 명확하고 H-B는 이론적이다.

### 🔴 θ는 placeholder다

**θ = 「관찰정보를 바탕으로 판단·추정하려는 개인의 특성·성과·기여 등의 대상」**

| 원칙 | |
|---|---|
| 🔴 | **latent psychological construct만을 뜻하지 않는다** |
| 🔴 | **관측값을 θ 칸에 넣지 않는다.** I와 θ의 구분이 무너진다 |
| 🔴 | **서로 다른 θ를 「개인성과」 하나로 합치지 않는다** — performance / ability / contribution / marginal productivity / firm-value contribution / 사례의 참 레이블을 구분한다 |
| 🔴 | **rating의 측정속성은 θ가 아니다** |
| ⭕ | **다만 상위 수준에서 관계가 있을 가능성까지 닫지 않는다** |

## 4. 🔴 분석 수준과 판정 단위

| | |
|---|---|
| 확인 | 조직 수준인가 · 개인 수준인가 · 팀 수준인가 |
| 🔴 금지 | 조직 수준 현상을 **개인 수준 지각으로 바로 전환**하는 것 |
| 🔴 금지 | 시스템의 **실제 특성**을 개인의 **perceived construct**로 바로 전환하는 것 |
| ⭕ | 전환이 필요하면 **명시적 theoretical transition으로 취급**하고 문서에 적는다 |

### 🔴 논문 전체 단일 판정을 하지 않는다

❌ **「이 논문이 우리 연구에 맞는다/안 맞는다」** · ❌ **논문 하나에 Direct / Adjacent / Exclude 하나를 부여**

⭕ **대신 「무엇에 대해 Direct인가」를 관계별로 기록한다.**

**예 — Steyvers 등 (2022)**

| 무엇에 대해 | 판정 |
|---|---|
| Human-AI output combination | 🟢 **Direct** |
| interactive joint production | 🔴 No |
| individual ability inference | 🔴 No |
| organizational appraisal | 🔴 No |
| production-structure 비교 | 🟡 **Structural relevance** |

### 🔴 Human-AI를 하나의 H로 묶지 않는다

⚠️ **확인된 다섯 편의 H-A가 서로 다르다** (`15-mapping-H-I-theta`).

| H-A | 문헌 |
|---|---|
| 인간‖AI 독립 수행 → 연구자 결합 | **Steyvers 등 (2022)** |
| 인간 초기 → AI 권고 → 인간 최종 | **Almog (2025)** |
| 개인 과업 + 선택적 AI 호출 | **Wu 등 (2026) HCOMP · HHAI** |
| 반복 상호작용 | **Kim 등 (2026)** |

🔴 **어느 하나를 「진짜 H」로 선택하지 않는다.** 📌 **반복적 joint production만을 포함조건으로 삼지 않는다.** ⭕ **output과 process를 모두 열어둔다.**

### 🔴 그 외 동일시 금지

| |
|---|
| **peer perception · hiring · platform evaluation을 formal performance appraisal로 동일시하지 않는다** |
| **self-belief와 actual ability를 동일시하지 않는다** |
| **correlation을 causal relation으로 확대하지 않는다** |
| **significance 없음을 equivalence로 해석하지 않는다** |
| **capability · independent performance · self-belief를 같은 것으로 취급하지 않는다** |
| **서로 다른 문헌의 `contribution`을 자동 동일시하지 않는다** |

## 8. 🔴 논문 기록 양식 — 14항목

**relevant로 판정한 논문마다 이 양식을 채운다.** 빈 항목은 ⬜로 남기고 채웠다고 하지 않는다.

```markdown
### <저자> (<연도>) — <제목>

| # | 항목 | 내용 |
|---|---|---|
| 1 | 정확한 서지정보 + 출판 상태 | |
| 2 | 실제 construct 명칭 | |
| 3 | construct의 원문 정의 (인용 위치 포함) | |
| 4 | H-A 작업/생산 구조 | |
| 5 | H-B 평가/추론 구조 | |
| 6 | level of analysis | |
| 7 | 실제 측정한 변수 (문항 수·척도) | |
| 8 | 실제 검증한 관계 — 다섯 관계 중 어느 것인가 | |
| 9 | 사용한 theory | |
| 10 | 핵심 empirical result | |
| 11 | 관계별 판정 — Direct / Structural precedent / Adjacent / Not established | |
| 12 | 이 논문으로 주장하면 안 되는 것 | |
| 13 | 원문 페이지 · 절 · 표 위치 | |
| 14 | 확보 등급 + 기계 검증 결과 | |
```

📌 **12번이 이 양식의 핵심이다.** 그 칸이 비어 있으면 그 논문은 아직 읽은 것이 아니다.

## 9. 🔴 아직 확정하지 않는 것

| |
|---|
| gap · RQ · IV/DV · theory · 방법론 |
| θ를 performance · ability · contribution 중 하나로 확정 |
| 후보 관계 중 하나를 연구대상으로 확정 |

📌 **현재 수렴 상태는 `16-performance-baseline`에 있다.**
