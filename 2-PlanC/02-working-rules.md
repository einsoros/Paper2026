# 진행방식 규칙

---

## 1. 🔴 다섯 층 구분 — 이 프로젝트의 1번 규칙

문헌을 읽을 때 다음을 **섞지 않는다.**

| # | 층 | 무엇 |
|---|---|---|
| **①** | **정의** | 논문이 실제로 **정의한** construct |
| **②** | **측정** | 논문이 실제로 **측정한** construct |
| **③** | **검증** | 논문이 실제로 **검증한** 관계 |
| **④** | **해석** | 저자가 **discussion에서 해석한** 것 |
| **⑤** | **추론** | **우리가 적용하면서 새로 추론하는** 것 |

🔴 **⑤를 ①~④인 것처럼 쓰면 안 된다.**

⚠️ 실제로 발생했던 오류가 전부 이 규칙 위반이다 — 저자 귀속 오류, 척도 문항수 오독, **construct 정의와 그 결과·설명을 동일시**, **인접 construct를 동일 construct로 취급**, **병렬 예측변수를 연쇄 매개로 서술**.

📌 특히 ①과 ④의 혼동이 잦다. 「저자가 관련연구에서 그렇게 말했다」는 ④이고, 검증된 construct가 아니다.

## 2. 🔴 분석 수준을 반드시 확인한다

| | |
|---|---|
| 확인 | 조직 수준인가 · 개인 수준인가 · 팀 수준인가 |
| 🔴 금지 | 조직 수준 현상을 **개인 수준 지각으로 바로 전환**하는 것 |
| 🔴 금지 | 시스템의 **실제 특성**을 개인의 **perceived construct**로 바로 전환하는 것 |
| ⭕ | 전환이 필요하면 **명시적 theoretical transition으로 취급**하고 문서에 적는다 |

## 3. 🔴 direct evidence와 adjacent evidence를 구분한다

| | |
|---|---|
| **Direct** | 우리 현상을 **직접** 연구한 것 |
| **Adjacent** | 인접하지만 **다른 것**을 연구한 것 |

⚠️ adjacent를 direct로 쓰면 심사에서 그 한 편으로 논문 전체가 흔들린다.

## 4. 확보 등급 표기

| 등급 | 의미 |
|---|---|
| 🟢 | **원문 전문 대조 완료** |
| 🟡 | 초록 · 2차 인용 수준 확인 |
| ⬜ | **검색 수준.** 서지도 미확정 |

🔴 **「검색으로 확인」과 「원문 대조」는 다르다.** 문서에 반드시 등급을 적는다.
🔴 **서지를 기억으로 쓰지 않는다.** 저자·연도·권호·쪽수는 원문이나 출판사 페이지에서 확인한다.

## 5. 검색 규칙

| | |
|---|---|
| ❌ | **「우리 모형을 지지하는 논문을 찾아라」** 방식으로 검색하지 않는다 |
| ⭕ | 우리에게 필요한 결과가 **나오지 않아도 된다** |
| ⭕ | 🔴 **반증 자료를 별도로 찾는다** |
| ⭕ | 기존 Plan A/B/C 문헌을 **출발점으로 삼지 않는다.** 새 검색에서 같은 논문이 다시 나오는 것은 허용 |
| ⭕ | **단계 결과에 따라 다음 검색 질문 자체를 수정한다** |

## 6. 문서 규칙

| # | |
|---|---|
| 1 | 근거 표기는 **「파일 → 절 제목」**. 행 번호는 쓰지 않는다 |
| 2 | **남은 일수를 문서에 쓰지 않는다.** 고정 날짜만 |
| 3 | **연구의의를 먼저 크게 만들지 않는다.** 문헌이 허용하는 만큼만 |
| 4 | 🔴 **정정은 지우지 않고 `05-corrections-log`에 남긴다** |
| 5 | 확정 전 항목은 ⬜로 표시하고, **확정된 것과 같은 문장에 섞어 쓰지 않는다** |
| 6 | 기존 Plan A · Plan B 폴더는 **이 트랙 때문에 수정하지 않는다** |

## 7. 🔴 논문 기록 양식 — 14항목

**relevant로 판정한 논문마다 이 양식을 채운다.** 빈 항목은 ⬜로 남기고 채웠다고 하지 않는다.

```markdown
### <저자> (<연도>)

| # | 항목 | 내용 |
|---|---|---|
| 1 | 정확한 서지정보 | |
| 2 | 실제 construct 명칭 | |
| 3 | construct의 **원문 정의** (인용 위치 포함) | |
| 4 | 인간-AI 관계와 업무맥락 | |
| 5 | 🔴 level of analysis | |
| 6 | 실제 **측정한** 변수 (문항 수·척도) | |
| 7 | 실제 **검증한** 관계 | |
| 8 | 사용한 theory | |
| 9 | 핵심 empirical result | |
| 10 | 🔴 **direct / adjacent 판정** | |
| 11 | 우리 연구에 **사용할 수 있는** 주장 | |
| 12 | 🔴 **이 논문으로 주장하면 안 되는 것** | |
| 13 | 원문 페이지 · 문장 위치 | |
| 14 | 확보 등급 + 최종 판정 | |
```

📌 **12번이 이 양식의 핵심이다.** 그 칸이 비어 있으면 그 논문은 아직 읽은 것이 아니다.
