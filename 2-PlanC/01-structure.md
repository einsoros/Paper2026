## 1. 세 가지 배치

### C-1 · 매개 유지 — 원래 주장을 살린다

```
귀속 모호성 ──▶ 평가 불확실성 ──▶ 분배공정성 지각
   IV              MV                  DV
```

| | |
|---|---|
| 🟢 | **연구자의 원래 주장이 그대로 유지된다** — 「가려낼 수 없다 → 예측할 수 없다 → 공정하다고 보기 어렵다」 |
| 🟢 | H1은 귀인이론 그대로. **H2만 바뀐다** |
| 🟢 | 논리가 오히려 짧아진다 — 「예측 못 함 → 내 몫이 제대로 올지 모름」이 「예측 못 함 → 규칙 충족 판단 불가」보다 직관적 |
| 🔴 | H2 이론 근거가 **Leventhal 절차 규칙 → 형평이론(Adams)** 으로 교체된다 |
| ⬜ | **「예측 불가 → 분배 불공정」 실증 앵커 미확인** |

### C-2 · MV를 측정가능성으로 교체

```
귀속 모호성 ──▶ 성과 측정가능성 지각 ↓ ──▶ 분배공정성 지각
```

| | |
|---|---|
| 🟢 | **Eisenhardt 명제 9**가 뒤 경로를 받친다 |
| 🔴 | **연구자의 원래 주장(예측 불가)이 사라진다** |
| 🔴 | **IV·MV 판별 위험** — 「기여를 가려내기 어렵다」와 「성과가 측정되기 어렵다」가 인접 |
| ⬜ | 측정가능성 **지각 척도** 미확인 |

### C-3 · 단층

```
귀속 모호성 ──▶ 분배공정성 지각
                   ↑
        (Eisenhardt는 이론적 근거로만)
```

| | |
|---|---|
| 🟢 | 단순 · 판별 위험 없음 · **Plan B의 상위 호환** (같은 단층인데 DV가 더 표준적) |
| 🔴 | **기제가 사라진다** — 「왜 그렇게 되는가」에 답이 없다 |

## 2. 현재 판단

📌 **C-1을 우선 검토한다.**

| 이유 | |
|---|---|
| **원래 주장 유지** | 몇 개월 파온 논리를 버리지 않는다 |
| **배분 이슈 도달** | 심사 권고 충족 |
| **H2가 짧아진다** | 현행 A에서 가장 약한 고리가 개선될 여지 |

⚠️ **다만 「예측 불가 → 분배 불공정」의 실증 앵커를 찾아야 한다.** 없으면 A와 같은 문제가 반복된다.

## 3. 변수와 척도

| 변수 | 내용 | 척도 | 상태 |
|---|---|---|---|
| **IV** 성과 기여 귀속 모호성 | AI 협업 산출물에서 자기 기여를 가려내기 어렵다고 지각하는 정도 | 현행 MC 4문항 재사용 | 🔴 신규 |
| **MV** 평가 불확실성 (C-1) | 그 기여가 어떤 평가로 이어질지 예측하기 어려운 상태 | 현행 MV 4문항 | 🔴 신규 |
| **MV** 측정가능성 지각 (C-2) | 자기 성과가 측정될 수 있다고 지각하는 정도 | ⬜ **미확인** | ⬜ |
| **DV** 분배공정성 지각 | 투입 대비 결과의 공정성 지각 | 🟢 **Niehoff & Moorman(1993) 4문항** · Colquitt(2001) | 🟢 리포 보유 |

📌 **DV가 이 안의 최대 강점이다.** 검증된 표준 척도이고 국내 번안 선례가 많다.

⚠️ **N&M(1993)의 분배공정성 4문항 예시** — 「내 성과는 공정하게 평가된다」·「내 급여 수준은 공정하다」·「승진 제도는 공정하다」
🔴 **첫 문항이 평가를 직접 언급한다.** IV·DV 판별에서 주의가 필요하다.

## 4. 🔴 IV·DV 판별 경계

| | 무엇을 묻는가 |
|---|---|
| **IV** | **기여를 가려내는 과정**의 어려움 — 「인간과 AI의 기여를 구분하기 어렵다」 |
| **DV** | **결과 배분**의 공정성 — 「내 투입에 비추어 받은 것이 공정한가」 |

### ❌ 절대 쓰면 안 되는 IV 문항

> 「내 기여가 보상에 제대로 반영되지 않을 것 같다」

⚠️ **DV를 뒤집어 물은 것이다.** IV는 **산출물**, DV는 **배분 결과**를 지시해야 한다.
