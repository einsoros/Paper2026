## 5. ⬜ 선행연구 탐색 — 「노력–평가 결과 대응」

> MV 재정의가 성립하려면 **「자기 노력·기여가 평가에 반영되는 정도에 대한 지각」**을 다룬 선행연구가 필요하다.

| 탐색 방향 | 검색어 후보 |
|---|---|
| 기대이론 계열 | expectancy · instrumentality · effort-reward expectancy |
| 공정성 계열 | perceived accuracy of performance appraisal · appraisal accuracy perception |
| 평가 신뢰 계열 | performance-reward linkage · effort-performance-outcome contingency |
| 심리적 계약 | perceived contract fulfillment |

### 🔴 [08-25 탐색 결과] 해당 구성개념이 이미 존재한다 — **perceived appraisal accuracy**

⚠️ 웹 검색으로 확인. **원문 대조는 아직 하지 않았다.**

| 항목 | 확인된 것 |
|---|---|
| 구성개념 | **perceived (performance) appraisal accuracy** — 「내 평가가 내가 한 일을 정확히 반영하는가」에 대한 지각 |
| 계보 | **Landy, Barnes-Farrell & Cleveland (1980)** *JAP* 65(3) — perceived accuracy and fairness of performance evaluation. 이 계열의 출발점으로 보인다 |
| 최근 척도 | **Sharma, Sharma & Agarwal (2016)** — perceived PMS accuracy **12문항, α=.83** · 정확성과 공정성을 **두 요인으로 분리** |
| 실측 문항 예 | 「내 평가 등급은 내가 한 일의 양을 반영한다」 · 「내 최근 평가는 내가 직무에 투입한 **노력(effort)**에 근거한다」 · 「내 평가 등급은 내 성과의 참된 모습을 보여준다」 |
| 관련 문헌 | Levy & Williams (1998, 2004) · Thurston & McNall (2010) · Kavanagh, Benson & Brown (2007) |

### 무엇을 뜻하는가

| | |
|---|---|
| 🟢 **MV 재정의의 척도가 이미 있다** | 신규 개발이 아니라 **기존 척도 번안**이 된다. V6(신규 척도 위험)이 크게 줄어든다 |
| 🟢 **IV와 축이 확실히 갈린다** | 이 척도는 「평가 등급」을 지시 대상으로 하고, IV는 「산출물의 기여」를 지시 대상으로 한다 → **V1 완화** |
| 🟢 **DV와 이론이 이어진다** | 정확성/공정성을 두 요인으로 분리한 선례가 있어, Leventhal accuracy 규칙과 정합 |
| 🔴 **다만 방향이 반대다** | 기존 척도는 **사후 평가에 대한 지각**(내 평가가 정확했다)이고, 본 연구 MV는 **사전 불확실성**(정확히 반영될지 모르겠다)이다. **역채점 또는 미래시제 번안이 필요** |
| 🔴 **그리고 공백이 줄어들 수 있다** | 이 계열이 이미 절차공정성과의 관계를 다뤘다면 H2의 「앵커 0」 판정이 바뀔 수 있다 |

### ⬜ 즉시 확인할 것

| 순 | 무엇 |
|---|---|
| 1 | **Landy et al. (1980)** *JAP* 원문 — 최초 척도 문항과 정의 |
| 2 | **Sharma et al. (2016)** — 12문항 전문 · 정확성/공정성 2요인 구조 |
| 3 | 🔴 **이 계열이 절차공정성을 결과변수로 놓은 연구가 있는가** — 있으면 H2 앵커가 생기고, 동시에 공백 주장이 약해진다 |
| 4 | 사전 불확실성 형태로 번안한 선례가 있는가 |

### 🔴 [08-25 2차 탐색] 결과 — 세 가지 확인

> ⚠️ **전부 웹 검색 결과이며 원문 대조는 하지 않았다.** 서지 확정과 문항 확보는 별건이다.

#### ① 🔴 정확한 대응 이론은 instrumentality가 아니라 **expectancy(E→P)**였다

| | |
|---|---|
| 확인된 정의 | Vroom 기대이론의 **expectancy** = *「일정 수준의 노력이 특정 성과 평정으로 이어질 것이라는 믿음」* |
| instrumentality | 「성과가 **보상**으로 이어질 것이라는 믿음」 — 본 연구와 다르다 |
| 🔴 **판정** | 앞선 기록에서 instrumentality를 인접 이론으로 적은 것은 **틀렸다.** 본 연구 MV의 대응은 **expectancy(노력 → 평정)**다 |

📌 그리고 이것은 리포의 기존 이론 근거와 **충돌하지 않는다** — Weiner 기대원리도 「원인 귀속 → 미래 기대」다. **두 이론이 같은 자리를 다른 언어로 말하고 있다.**
⬜ 확인 필요 — Vroom expectancy와 Weiner expectancy principle의 관계를 어떻게 정리할 것인가. 둘을 병렬로 쓰면 이론 층이 늘어난다.

#### ② 사전형(prospective) 불확실성 — **전용 척도는 찾지 못했으나 개념 선례는 있다**

| | |
|---|---|
| 찾은 것 | 평가 주기(appraisal interval) 연구에서 **불확실성을 「미래 상태를 정확히 예측할 수 없는 정도」로 정의**하고, 주기가 길어지면 「자기 주도적 노력이 결과로 이어질지 예측할 수 없어」 **직무 관련 불확실성이 증가**한다고 논증 |
| 🔴 못 찾은 것 | **「평가 정확성에 대한 사전 불확실성」을 직접 측정한 척도** |
| 판정 | 성준님 MV는 **여전히 신규 측정**이다. 다만 **개념적 선례는 있어** 정의를 정당화할 근거가 생겼다 |

#### ③ perceived appraisal accuracy → 절차공정성 — **직접 앵커는 아직 미확인**

| 찾은 것 | 함의 |
|---|---|
| ⭐ **Erdogan(2002)** — 절차공정성을 **system PJ · rater PJ 두 차원**으로 분리. **평가 기준의 지각된 타당성(perceived validity of performance criteria)**과 **기준에 대한 지식**이 system PJ와 관련 | 🔴 **리포에 이미 있는 문헌이다.** MOD 근거로만 쓰고 있었는데, **H2 앵커 후보**이기도 하다 |
| Landy, Barnes-Farrell & Cleveland (1978·1980) | 공정성과 **정확성 지각**을 함께 다룬 초기 연구 |
| Keeping & Levy (2000) *JAP* | 평가 반응(정확성·공정성 포함) **측정·모형화·방법편의** 정본 |
| 🔴 못 찾은 것 | 정확성 지각을 **매개변수**로 놓고 절차공정성을 결과로 둔 연구 |

📌 ★★ **Erdogan(2002)의 「평가 기준의 지각된 타당성 → system 절차공정성」이 본 연구 H2와 구조가 같다.** 원문 대조로 이것이 앵커가 되는지 확인하면 **H2의 앵커 0 판정이 바뀔 수 있다.**
⚠️ 다만 그쪽은 **평가 기준의 타당성**이고 본 연구는 **기여–평가 대응의 불확실성**이다. 같은지 다른지는 원문을 봐야 한다.
