## 우선순위 A — 선행연구 조사 ✅ 전체 완료

### A1. 공헌 2번 진위 확인 ✅ (07-31)
- Done = 정확히 같은 연구 유무 확인 + 조각별 인접연구 목록 + 공헌 좁힐 방향
- 결과: "AI 협업 귀속 모호성 → 평가 불확실성 → 절차공정성"을 함께 다룬 연구 **확인 범위 내 없음**(신규성 근거). 조각(AI+공정성 / UMT+공정성 / AI평가 블랙박스불확실성 / AI협업 귀속모호성)은 각각 존재.
- 핵심 구분(07-31 심화): 기존은 **AI가 평가 시스템 쪽**(평가자·블랙박스), 본 연구는 **AI가 업무 수행 쪽**(협업 도구). "AI 결합"의 위치가 다름.

### A2. H1 확장 문헌 ✅ (07-31)
- Done = 뒷받침 문헌 확보 or 논증 대체 확정
- 결과: 기대원리는 Weiner로 확립(보유). '성과 기대→평가 기대' 직접 논문 없음 → **논리 논증으로 대체 확정**(범위 설정으로 전제 확보). 신규 필수 논문 없음.
- 심화: 귀인 3차원(소재성·안정성·통제가능성) 체득. AI 협업은 소재성(내부 통제 vs 외부 AI)·통제가능성이 한 산출물에 공존·분열 → 귀속 판정 불가 → 불확실성. (분해는 미래연구, 논문엔 통합개념 1겹)

### A3. UMT 불확실성 출처 정리 ✅ (07-31)
- Done = UMT가 다룬 출처 목록화 → 본 연구 출처의 위치 확정
- UMT 기존 출처: 실존적 자기불확실성 / 사망 현저성 / 문화적 세계관 위협 / 조직변화·권위신뢰 / 과업 불확실성 / 정보 불확실성 → **모두 외부 상황·실존 기반**.
- 본 연구 출처(자기 기여 귀속 모호성=내부 자기식별 불가)는 미탐색.
- **논리 정정(중요, 07-31)**: "UMT가 안 다룸 = 신규성"은 성급(성준 지적). 신규성은 **A1(주제 전체 검색)**이 담당, A3는 **차별화(UMT 출처 지형 내 위치)** 담당. 설명력은 귀인이론+UMT 일반명제에서 옴, "미탐색"에서 오지 않음.
