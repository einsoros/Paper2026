# Analysis Plan — 통계 분석 방법론

> 본 문서는 "무엇을 측정하나(measurement-items)"·"모델·가설(research-model)"과 구분되는 **"측정한 것을 어떻게 검정하나"**를 정리한다.
> 정밀 수치(검정력·효과크기)는 척도 확정 후(6단계)에 확정한다. 현재는 방법 세트·선택 근거·표본 방향까지.

## 1. 분석 흐름 (순서)

```
① 조작 점검 (독립표본 t검정)
   └ IV 2조건이 실제로 귀속 모호성을 다르게 지각시켰는지 확인
② 신뢰도 (Cronbach's α) · 타당도 (EFA/CFA)
   └ 특히 판별타당도(AVE, HTMT) — IV·MV·DV가 별개 개념임을 통계로 입증 (순환 방어)
③ 공통방법편의(CMV) 점검 (Harman's single-factor / marker variable)
   └ MV·DV를 같은 응답자가 자기보고 → 상관 부풀림 방어 (단일시점 한계와 직결)
④ H1 : 집단 간 평균차 (t검정 / 일원 ANOVA)
⑤ H2·H3 : 매개 — PROCESS Model 4 + 부트스트래핑
⑥ H4 : 조절된 매개 — PROCESS Model 14 (상호작용항 MV×MOD) + 부트스트래핑
   └ 부트스트래핑 5,000회, 95% 신뢰구간
```

## 2. 가설 ↔ 방법 매핑

| 가설 | 내용 | 검정 방법 |
|---|---|---|
| H1 | 귀속 모호성(고) → 평가 불확실성↑ | 독립표본 t검정 / 일원 ANOVA (집단 간 평균차) |
| H2 | 평가 불확실성 → 절차공정성↓ | 회귀 (PROCESS 내) |
| H3 | 평가 불확실성이 IV→DV 매개 | PROCESS Model 4 (부트스트래핑 간접효과) |
| H4 | 절차 명확성이 MV→DV 완화 | PROCESS Model 14 (상호작용항 유의성 + 조건부 간접효과) |

- **H4 지지 = 상호작용항(MV×MOD) 계수 유의** (주효과 b1·b2가 아님).

## 3. 방법 선택 근거 (방어 논리)

### 왜 PROCESS인가
- IV가 실험 조작(범주형 2조건)이고 매개·조절 구조가 단순 → 회귀 기반 PROCESS가 정합적.
- 부트스트래핑은 매개 간접효과 검정의 현행 표준 (정규성 가정 불필요).
- Hayes(2018) Model 4(매개)·Model 14(MV→DV 경로 조절)가 본 모델과 정확히 대응.

### 왜 다음은 쓰지 않는가 (혼동 방지)
- **구조방정식(SEM, AMOS/Lavaan)** : 잠재변수 다중 관계에 강하나, 본 모델은 그 정도로 복잡하지 않음. IV가 실험 조작이라 PROCESS가 더 적합. SEM은 과잉이며 방어 부담만 늘어남. → 채택 안 함.
- **Baron & Kenny(1986) 위계적 회귀 매개** : 구식·저검정력. 부트스트래핑으로 대체. → 채택 안 함.
- **다층모형(HLM)** : 응답자가 조직에 내포된 구조가 아니면 불필요. 개인 수준 단일 층 → 불필요.

> 원칙: "더 고급 방법 = 더 좋은 연구"가 아니라 "설계에 맞는 방법 = 좋은 연구". 설계가 방법을 결정한다.

## 4. 표본 크기 (사전 검정력 분석 방향)

- 전제: α=0.05, 목표 검정력=0.80, **중간 효과크기 가정**(f²≈0.15 / β≈0.3).
- 검정별 필요 N은 다르며, **가장 큰 것(H4)이 표본을 결정**:

| 검정 | 대략 필요 N (중간 효과) |
|---|---|
| 집단 간 평균차 (H1) | 조건당 ~64, 총 ~128 |
| 매개 (H3, Model 4) | ~150 안팎 |
| **조절된 매개 (H4, Model 14)** | **~200 이상** ★ 상호작용은 검정력 낮음 |

- **잠정 목표: 총 250명** (H4 유지 + 결측·불성실 10~15% 감안, 2조건 균등 배분).
- H4 축소(매개만) 시 → ~150명.
- 정밀 산출: 조절된 매개는 공식 해가 없어 **Monte Carlo 검정력 분석**(R `pwr`·`bmem`, Schoemann et al. 앱 등)으로 6단계에서 확정. G*Power는 상호작용 회귀항까지만.
- 프로포절 서술(권장): "중간 효과크기 가정 시 조절된 매개 검정을 위해 약 200명 이상이 요구되며, 결측을 고려해 250명을 목표로 한다. 정확한 표본은 사전 검정력 분석으로 확정한다."

## 5. 결과가 예측과 다를 경우 (비유의 대비)

- **비유의 = 실패 아님.** 사회과학 가설검정은 "제대로 검정했으면" 결과가 어느 쪽이든 기여. 석사 논문은 결과가 아니라 연구 수행 능력을 평가.
- **세 경우 구분:**
  1. 진짜 효과 없음(귀무 지지) → 이론 예측 반증, 그 자체가 발견. 논의에서 이론적 해석.
  2. 효과 있으나 검정력 부족(2종 오류) → 한계로 정직히 서술, 표본 250 목표가 이 위험 완화.
  3. 설계·측정 문제 → 사전 예방(판별타당도·조작점검·교란통제)으로 방지.
- **부분 지지가 가장 흔하고 정상.** 예: H1~H3 유의, H4만 비유의 → 매개 중심 구조가 논문을 지탱. (H4를 탐색적으로 둔 이유.)
- **금지:** HARKing(결과 보고 가설 사후조정)·p-hacking. 정직한 설계와 있는 그대로의 보고가 학위논문 윤리.

## 6. 미확정 (6단계 과제)

- [ ] 사전 검정력 분석 정밀 산출 (Monte Carlo, 효과크기 확정)
- [ ] CMV 점검 방법 확정 (marker variable 채택 시 marker 문항 설계)
- [ ] 판별타당도 기준 확정 (AVE>0.5, HTMT<0.85 등)
- [ ] H4 유지 여부 (지도교수 면담) → 표본 목표 확정(250 vs 150)

---

_방법 세트 요약: 조작점검(t) → 신뢰도·타당도(CFA·판별타당도) → CMV → H1(t/ANOVA) → H2·H3(Model 4) → H4(Model 14), 부트스트래핑 5,000회 95% CI._
