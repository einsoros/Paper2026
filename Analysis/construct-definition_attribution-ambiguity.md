# Construct Definition: 성과 기여 귀속 모호성

## Working Definition

성과 기여 귀속 모호성은 인간과 AI가 공동으로 산출한 업무 성과에서, 평가자가 인간 구성원의 기여와 AI의 기여를 명확히 분리하여 식별하기 어렵다고 지각하는 상태를 의미한다.

## Core Logic

기존 성과평가는 성과가 개인의 역량, 노력, 판단, 책임에 비교적 명확히 귀속될 수 있다는 전제를 가진다. 그러나 생성형 AI 기반 협업에서는 아이디어 생성, 초안 작성, 수정, 판단 보조, 대안 탐색이 반복적으로 얽히면서 산출물이 인간 단독의 결과인지, AI 지원의 결과인지, 혹은 둘의 공동 산물인지 구분하기 어려워진다.

이때 평가자는 성과의 질을 볼 수는 있지만, 그 성과가 누구의 기여에서 비롯되었는지 판단하기 어려워진다. 이 식별 곤란이 성과 기여 귀속 모호성이다.

## What It Is

- 산출물 이후에 발생하는 사후적 판단 문제
- 성과 원천이 인간인지 AI인지 분리하기 어려운 상태
- 평가자가 개인 역량, 노력, 판단의 기여분을 식별하기 어려운 상태
- 공동 생성 성과를 개인 중심 평가체계에 넣을 때 발생하는 평가 가능성 문제

## What It Is Not

| Similar concept | Why it is different |
|---|---|
| 역할 모호성 | 역할 모호성은 업무 수행 전 "무엇을 해야 하는가"의 불명확성이고, 성과 기여 귀속 모호성은 성과 산출 후 "누구의 기여인가"의 불명확성이다. |
| 과업 모호성 | 과업 자체가 불분명한 문제가 아니라, 완성된 산출물의 기여 원천을 구분하기 어려운 문제다. |
| 책임 회피 | 행위자가 책임을 회피하는 전략적 행동이 아니라, 평가자가 기여 원천을 식별하기 어려운 인지적 평가 조건이다. |
| 알고리즘 공정성 | AI가 평가자로서 편향되는 문제가 아니라, AI와 협업한 인간을 어떻게 평가할 것인가의 문제다. |
| AI 사용 낙인 | AI를 썼다는 이유로 낮게 평가하는 사회적 처벌이 아니라, 평가 근거의 식별 가능성이 낮아지는 문제다. |

## Boundary Sentence

본 연구에서 성과 기여 귀속 모호성은 역할 수행 전의 과업 불확실성이 아니라, 인간-AI 공동 생성 이후 성과의 기여 원천을 인간 개인에게 어느 정도 귀속할 수 있는지에 대한 사후적 식별 불확실성으로 정의된다.

## Candidate Measurement Items

1. 이 성과가 구성원의 역량에서 비롯된 것인지 AI의 기여에서 비롯된 것인지 구분하기 어렵다.
2. 이 결과물에서 인간 구성원의 순수 기여분을 식별하기 어렵다.
3. 이 성과는 인간과 AI의 기여가 분리하기 어렵게 결합되어 있다.
4. 평가자가 이 성과의 실제 기여 주체를 판단하기 어렵다.
5. 이 결과물만으로 구성원의 실제 역량을 판단하기 어렵다.
6. AI의 개입 정도 때문에 성과의 개인 기여도를 명확히 평가하기 어렵다.

## Claims To Support With Literature

- 인간-AI 협업은 산출물의 공동 생성성을 높인다.
- 공동 생성성은 기여 원천의 분해 가능성을 낮춘다.
- 기여 원천 식별이 어려울수록 평가 절차의 정확성과 설명 가능성은 약화된다.
- 평가 절차의 정확성과 설명 가능성이 약화되면 절차공정성 지각이 낮아진다.
