# Paper Project Instructions

Use this project as a paper-writing and literature-analysis workspace.

## Ground Rules

- Treat Zotero as the source of truth for bibliographic metadata, PDFs, citation keys, and BibTeX.
- Treat `Sources/Papers/` as the source of truth for paper-specific reading notes.
- Treat `Knowledge/` as a curated layer. Only promote claims after they are supported by paper notes.
- Treat `Writing/` as the drafting layer. Keep unsupported claims visibly marked.
- Do not invent citations, DOIs, authors, venues, or results.
- If evidence is weak or missing, write `needs evidence` instead of smoothing it over.
- Prefer comparison tables before writing broad literature-review prose.

## Default Workflow

1. Create or update paper notes in `Sources/Papers/`.
2. Extract comparable features into `Analysis/paper-feature-matrix.md`.
3. Summarize stable patterns in `Knowledge/Claims.md`.
4. Identify unresolved tensions in `Knowledge/Research-Gaps.md`.
5. Draft writing in `Writing/literature-review.md`.
6. Convert mature draft sections into LaTeX under `Writing/latex/sections/`.

## Paper Note Standard

Every paper note should include:

- citation key
- full title
- research problem
- main claim
- method
- data or evidence base
- main findings
- limitations
- relation to other papers
- relevance to the current project

## Writing Standard

Every paragraph in a literature review should answer at least one of these:

- What is known?
- What is disputed?
- What method or evidence changed the field?
- What limitation remains?
- Why does this matter for the current paper?
