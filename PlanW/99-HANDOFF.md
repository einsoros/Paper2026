## 0. 새 스레드는 여기서 시작한다

**이 파일이 유일한 진입점이다.** 다른 문서를 먼저 열지 않는다.

1. 이 파일을 끝까지 읽는다.
2. §1 라우팅 표를 보고 **지금 필요한 문서만** 연다.
3. §7 시작 게이트를 통과한다. 통과 전에는 아무 작업도 시작하지 않는다.

`Archive/` 는 어떤 경우에도 열지 않는다. 폐기된 Plan A/B/C 보존 영역이다.

## 7. 시작 게이트

새 스레드는 작업을 시작하기 전에 다음을 **한 문단으로 요약해 제출하고 멈춘다.**

1. 현재 backbone 과 그 근거등급
2. 확정된 것
3. 미확정인 것
4. 직전 Mission 결과와 문서 반영 여부
5. 다음에 할 일

사용자 확인 전에는 **검색 · 판정 · 파일 작성 · git 명령을 시작하지 않는다.**
확인 없이 낸 산출물은 폐기 대상이다. 단계가 끝날 때마다 같은 게이트를 다시 통과한다.

## 8. 금지된 해석

1. 출발점의 경로(autonomy → role breadth → performance)를 **검증된 관계로 취급하지 않는다.** D등급이다.
2. W-1 논문의 내용을 기억 · 검색 · 초록으로 채우지 않는다. 원전 정독 결과가 문서에 반영되기
   전까지 `02` · `03` · `04` 에 A등급 기록이 없는 것이 정상이다.
3. AI / GenAI / automation / digitalization / algorithmic management / Human-AI collaboration 을
   연구모형에 연결하지 않는다.
4. 사용자의 현업 사례를 backbone 정당화 근거로 사용하지 않는다.
5. 새 변수 · mediator · moderator · contribution 을 원전 확인 전에 발명하지 않는다.
6. 검색 부재를 research gap 으로, 비유의성을 관계 부재로 취급하지 않는다.
7. 새 `.md` 파일을 만들지 않는다. 8개 고정문서를 수정한다.
8. 다음 Mission 을 임의로 시작하지 않는다. 보고 후 지시를 기다린다.
