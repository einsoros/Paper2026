# 집필 표기 기준

> **서술 수위와 금지 표현은 [[Writing_Notes]]**, 여기는 **표기와 형식**만 다룬다.
> 2장 초안 통독(2026-10-24)에서 발견된 불일치를 기준으로 작성.
>
> **2026-10-24 확정.** 집필 시 이 문서를 기준으로 하고 표기를 다시 묻지 않는다.

---

## 1. 학위논문 양식 — 확정 사항

학교 양식(`thesis_format_kor_250410.docx`)이 정한 범위다.

```
용지      4·6배판(B5) = 182 × 257mm
여백      초록 이후 — 상하 3cm 이상, 좌우 2cm 이상
          표지 · 속표지 · 심사완료검인서 — 사방 3cm 이상
본문      10~12pt
줄간      1.5~2.5줄 (150~250%)
서체      명조체 · 고딕체 또는 유사 서체 (KoPub, 윤명조/윤고딕 가능)
쪽번호    초록~본문 전 로마 소문자(i, ii, iii) / 서론부터 아라비아 숫자(1, 2, 3)
장 번호   아라비아 숫자(1, 2, 3) / 부록은 영문 알파벳(A, B)
```

**확정 (2026-10-24)** — **본문 11pt · 줄간 200%.** 학교 양식 범위(10~12pt, 1.5~2.5줄) 안이며,
지도교수가 **학교 가이드 범위 내면 문제없다**고 확인하였다.

**표 · 그림**
- 본문에 표가 있으면 **표 목차**, 그림이 있으면 **그림 목차**를 반드시 작성
- 번호는 **장 기준**으로 한다 — 표 2.1, 표 2.2, 표 3.1 … / 그림 2.1, 그림 3.1 … **확정**
- 한글 논문이라도 **표 제목과 그림 제목은 영문 작성 가능**

## 2. 문헌 인용 표기

### 2-1. 본문 서술형

```
단독 저자     Parker(1998)는 …
2인 저자      Risko와 Gilbert(2016)는 …
              Gist와 Mitchell(1992)은 …
3인 이상      Zhu 등(2026)은 …
```

⚠️ **본문에서는 "와/과"를 쓰고 "&"를 쓰지 않는다.**

### 2-2. 괄호형 — 확정

**영문 원표기를 유지한다.**

```
2인 저자    … 관계될 수 있다(Risko & Gilbert, 2016).
            … 형성된다(Gist & Mitchell, 1992).
3인 이상    … 보고되었다(Zhang et al., 2026).
단독        … 다루어져 왔다(Parker, 1998).
```

⚠️ **본문 서술형과 괄호형의 표기가 다르다는 점에 주의한다.**

```
본문 서술형   Risko와 Gilbert(2016)는 …        "와/과"
괄호형        … 있다(Risko & Gilbert, 2016).    "&"
```

### 2-3. 괄호형을 쓰는 자리

본문 서술형을 기본으로 하되, **앞 절에서 이미 다룬 내용을 가리킬 때**만 괄호형을 쓴다.

```
예   2.3에서 살펴본 바와 같이 외부 인지자원의 사용은 … 관계될 수 있다(Risko & Gilbert, 2016).
```

## 3. 용어 표기

### 3-1. 통일할 것

| 쓸 것 | 쓰지 않을 것 | 비고 |
|---|---|---|
| **생성형 인공지능** | 생성형 AI | 본문 42회 대 1회. **그림 · 표 안에서는 축약 허용** |
| **인공지능** | AI | 본문 전체 |
| **의존적 인지위임** | 의존적 위임 | **본 연구 변수를 가리킬 때.** 아래 예외 참조 |

### 3-2. "의존적 위임" 을 쓰는 예외

**Zhu 등(2026)의 개념 쌍을 설명할 때만** 쓴다. 원 개념이 "의존적 위임 / 자율적 위임"
이므로 그 대비를 설명하는 2.6 에서는 자연스럽다.

```
허용   의존적 위임은 사용자가 인공지능을 자기 사고의 대체물로 다루는 경우로 …
       반면 자율적 위임은 …

불가   의존적 위임이 독립수행 자신감과 부적으로 연결될 것이라고 …
       → "의존적 인지위임이" 로 쓴다
```

### 3-3. 영문명과 약어

**2.5~2.9 에서 각 구성개념을 정의할 때 최초 1회만** 도입한다.

```
업무 관련 생성형 인공지능 활용(Work-related Generative AI Use, WAU)
의존적 인지위임(Dependent Cognitive Offloading, DCO)
독립수행 자신감(Subsequent Autonomous Capability, SAC)
역할확장 자기효능감(Role Breadth Self-Efficacy, RBSE)
```

이후 본문은 **한국어 명칭을 기본**으로 하되, **연구모형 · 가설 · 표 · 그림**에서는 약어를 쓴다.

⚠️ **2.1~2.4 로 거슬러 올라가 약어를 심지 않는다.** 구성개념을 공식 정의하기 전이다.

### 3-4. 분석기법 약어

**처음 쓸 때 한국어 → 원어 → 약어** 순으로 푼다.

```
구조방정식모형(Structural Equation Modeling, SEM)
확인적 요인분석(Confirmatory Factor Analysis, CFA)
최대우도법(Maximum Likelihood, ML)
강건 최대우도법(Maximum Likelihood Robust, MLR)
평균 · 분산 조정 가중최소제곱법(Weighted Least Squares Mean and Variance adjusted, WLSMV)
이질특성-동질특성 비율(Heterotrait-Monotrait Ratio, HTMT)
평균분산추출(Average Variance Extracted, AVE)
다집단 확인적 요인분석(Multi-Group Confirmatory Factor Analysis, MG-CFA)
```

## 4. 중복 처리

### 4-1. 발견된 중복 — 2장

**2026-10-24 처리 완료.**

| 내용 | 등장 | 처리 |
|---|---|---|
| Zhang et al.(2026)의 N = 541 과 WAU–RBSE 정적 관련 | 2.5 · 2.9 · 2.12 | **2.5 에서 삭제함.** 2.5 는 척도를 규정하는 절이며 결과까지 말할 필요가 없다. 2.9(AI 맥락 관련성)와 2.12(H2 근거)는 역할이 달라 유지 |
| "두 특성이 경험적으로 구별될 수 있다는 점은 최근 보고되었다" | 2.2 · 2.7 | **2.7 의 표현을 바꿈** |

### 4-2. 중복을 허용하는 경우

같은 사실이라도 **역할이 다르면** 반복할 수 있다. 다만 **같은 문장을 그대로 쓰지 않는다.**

```
허용   2.9 — AI 맥락에서도 관련이 보고되었다 (구성개념 규정)
       2.12 — β = .347 (가설 근거)

불가   같은 수치와 같은 표현을 두 곳에서 반복
```

### 4-3. 수치를 두는 자리

**구성개념 규정 절(2.5~2.9)에는 수치를 쓰지 않는다.**
**가설 · 연구질문 도출 절(2.11~2.14)에서 처음 제시한다.**

```
2.8   Zhu 등(2026)은 의존적 위임과 독립수행 자신감 사이에 부적 상관을 보고하였다
2.11  … 부적 상관(r = −.23)을 보고하였으며 …
```

## 5. 절 사이 연결

**각 절의 마지막 문단이 다음 절을 불러온다.** 독립적 문헌 요약으로 쓰지 않는다.

```
2.1 끝   사용 여부나 사용량만으로 인지적 관여를 설명할 수 있는가
2.2 끝   인지적 판단을 외부에 맡기는 현상은 새로운 문제인가
2.3 끝   "내가 이 일을 할 수 있는가"라는 판단은 어떤 성격인가
2.4 끝   어떤 기준점에 관한 판단인지를 먼저 정해야 한다
```

⚠️ **덩어리 2(2.5~2.9)는 구성개념 규정이므로 이 원칙을 기계적으로 적용하지 않는다.**
정의 · 측정범위 · 인접개념 · 선행결과를 **같은 틀로 반복하면 템플릿처럼 읽힌다.**
그 틀은 집필 체크리스트로만 쓰고 문장은 각 개념의 쟁점에 맞게 전개한다.

## 6. 작업 메모 표기

초안 파일에서 작업 메모는 **`>` 인용 블록**으로 쓰고 **최종본에 넣지 않는다.**

```
> **작업 메모** — Kayes & Yoon 은 개념 논문이므로 "제기하였다" 수위를 유지했다.
```

파일 말미의 **검토 요청** 절도 같다.
