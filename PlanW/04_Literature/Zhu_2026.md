# Citation

Zhu, Q., Li, X., Dong, Y., Chang, P., & Fan, M. (2026).
*Not all cognitive offloading is equal: Distinguishing dependent and autonomous offloading to generative AI.*
**Frontiers in Psychology, 17**, 1878629. doi: 10.3389/fpsyg.2026.1878629

원문 전문 확인 (2026-09-20). 오픈액세스.

# What the source actually studied

생성형 AI로의 인지 오프로딩을 단일 차원으로 보지 않고
**의존적(dependent)** 과 **자율적(autonomous)** 으로 구분하고,
두 방식이 인지 주체성 전이와 내재적 동기를 경유해
네 가지 지각된 인지적 결과와 갖는 관계를 검토했다.

상위 이론 — 자율-의존 도움 유형론(Nadler, 1997, 2015) + 자기결정이론.
조절변수 — 메타인지 모니터링.

# Sample / Design

- 3차 시차설계 설문, 2주 간격
- 최종 **N = 589** — 대학생 516명 + **초기경력 근로자 73명**
- 평균연령 23.69 (SD 3.24), 여성 51.1%, 중국
- 참여조건 — 18세 이상, 학습·업무 인지과업에 생성형 AI 3개월 이상 사용
- 제외 — 주의점검 실패 17명, 직선형 응답 14명, 3분 미만 완료 11명
- Mplus 8.3, 최대우도 추정

# Construct / Measure

모든 척도 **5점 Likert** (1 = strongly disagree, 5 = strongly agree), 각 4문항.
Brislin(1986) 역번역으로 중국어 실시. **영문 문항은 Supplementary Appendix B**에 제시.

| 척도 | α | CR | AVE | 원 출처 |
|---|---|---|---|---|
| Dependent cognitive offloading | .773 | .85 | .59 | Risko & Gilbert(2016) 틀 + Koopmann(2016) 의존적 도움 척도 |
| Autonomous cognitive offloading | .767 | .85 | .59 | Koopmann(2016) 자율적 도움 척도 |
| **Subsequent autonomous capability** | **.793** | .87 | .62 | **Nadler(2015)에서 적응** |
| Cognitive agency transfer | .773 | .85 | .60 | 신규 개발 |
| Intrinsic motivation | .837 | .89 | .67 | Shin & Zhou(2003) 수정 |

**통제변수** — 성별, 연령, 교육수준, **AI 사용빈도, AI 사용경험(개월), 과업복잡성**

**SAC 정의 [A]** — "AI 보조 없이 유사 과업을 독립적으로 수행할 수 있다는 지각된 능력.
**기능적 자기효능감**('나 혼자 할 수 있는가?')을 포착한다."

# Key Findings

**영차상관 (Table 3, N = 589)**

| 관계 | r |
|---|---|
| **DCO – SAC** | **−.23**, p < .01 |
| DCO – AO | **.08**, p = .049 |
| AO – SAC | .20, p < .01 |
| DCO – 인지 주체성 전이 | .38, p < .01 |
| DCO – 내재적 동기 | −.19, p < .01 |

**구조모형 (표준화)** — DCO → 주체성 전이 β = .35 / DCO → 내재적 동기 β = −.23
주체성 전이 → SAC β = −.21 / 내재적 동기 → SAC β = .36 (모두 p < .001)

**간접효과 (bias-corrected bootstrap 10,000)**
DCO → SAC via 주체성 전이 β = −.07 [−.11, −.04] / via 내재적 동기 β = −.09 [−.12, −.05]

**확인적 요인분석** — 11요인 모형 χ²(847)=1825.22, CFI=.92, TLI=.91, RMSEA=.044, SRMR=.042.
DCO·AO 병합 모형은 유의하게 악화 Δχ²(10)=726.53, p<.001.
판별타당도는 **Fornell-Larcker 기준** 사용. HTMT 미사용.

**하위표본 비교** — 학생(n=516) vs 근로자(n=73). 전반적 패턴 동일.
단 DCO → 내재적 동기의 부(−) 관계가 **근로자에서 더 강했다**(β = −.47 vs −.18, 집단 조절 β = −.26, p = .022).

# [A] Directly Supported

- DCO는 AI 보조 에피소드 동안 **인지작업이 배분되는 과업수준의 방식**이며, 전반적 특성·태도·역량이 아니다
- DCO는 **전체 사용빈도와 무관**하다. AI 의존성(사용량·갈망·통제상실로 지표화)과 구별된다
- 사용자는 AI 의존성이 높으면서 자율적으로 관여할 수도, 거의 쓰지 않으면서 의존적으로 쓸 수도 있다
- DCO와 AO는 **거의 직교하는 두 차원**이며 단일 연속선의 양극이 아니다
- SAC는 기능적 자기효능감이며 지각된 것이지 실증된 능력이 아니다
- 저자들이 자동화 만족, 맹목적 신뢰, 비판적 AI 리터러시, 자기조절학습 등 **5개 인접개념과의 경계**를 서술했다
- 척도는 **예비적·영역특정적 도구**이며 완전한 심리측정 검증은 후속과제라고 명시했다
- 직업별 반복검증 필요를 future research에 명시했다

# [C] PlanW Interpretation

- DCO를 "동일한 업무수행 안에서 핵심 인지활동이 인간과 AI 사이에 배분되는 방식"으로
  **새로운 수행조건**의 자리에 놓는 것은 PlanW의 이론적 연결이다.
  저자들은 SCT나 Gist & Mitchell 틀에서 이를 논하지 않았다
- SAC를 '독립성의 경계에 관한 수행가능성 판단'으로 부르는 것은 PlanW의 내부 표현이며
  **원저자 용어가 아니다**

# Limits for PlanW

- **표본이 사실상 학생 중심**(87.6%). 근로자 하위표본 73명. 척도가 국내 지식근로자에서 작동할지 미확인
- 모든 결과변수가 **자기보고된 지각**이며 수행 기반 측정이 아니다
- 저자들이 인과 주장을 하지 않는다 — 3차 시차설계이나 매개의 인과를 확립하지 못한다고 명시
- 새 척도라 공통방법편의 우려를 저자들이 인정
- **측정된 인접 구성개념에 대한 경험적 판별타당도는 미확립**
- DCO→SAC **직접경로를 모형에 두지 않았다**
