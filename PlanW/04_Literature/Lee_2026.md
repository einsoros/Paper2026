# Citation

Lee, E. H., Yin, Y., Jia, N., & Wakslak, C. J. (2026).
*Relying on AI at work reduces self-efficacy, ownership, and meaning while active collaboration mitigates the effects.*
**Scientific Reports, 16**, 13583. doi: 10.1038/s41598-026-42312-6

University of Southern California, Marshall School of Business.
검색 결과로 확인 (2026-10-08). 논문 전문은 미확인.

# What the source actually studied

생성형 AI를 **수동적으로 사용하는 방식**과 **능동적으로 협업하는 방식**이
근로자의 자기효능감 · 심리적 소유감 · 일의 의미에 각각 어떻게 연결되는지를 검토.

# Sample / Design

- **사전등록 실험** — 직업별 글쓰기 과업, 세 조건
  - AI 미사용
  - **수동적 사용** — AI 생성물을 복사해 사용
  - **능동적 협업** — 먼저 초안을 작성한 뒤 AI로 다듬음
- **후속 직장인 설문** — 실제 업무 맥락에서 상관 확인

# Key Findings

| | |
|---|---|
| 결과변수 | **AI-independent self-efficacy** · 심리적 소유감 · 일의 의미 |
| 수동적 사용 | 세 결과변수 모두 저하 |
| **지속성** | 효능감과 의미의 저하가 **참가자가 수작업으로 돌아간 뒤에도 지속** |
| 능동적 협업 | 독립 수행과 비슷한 수준으로 보존 |
| 상관 | 수동적 의존 – 자기효능감 **r = −.45**, p < .01 (다른 연구에서 r = −.44) |

# [A] Directly Supported

- 수동적으로 AI 산출물을 가져다 쓰는 방식은 **AI 없이 수행할 수 있다는 자기효능감**과 부(−)적으로 연결된다
- 그 저하는 AI 사용 장면에 국한되지 않고 **이후 수작업 상황까지 이어진다**
- **사용 여부가 아니라 사용 방식**이 결과를 가른다
- 사전등록 실험이므로 상관연구보다 강한 설계다

# [C] PlanW Interpretation

- Lee의 `AI-independent self-efficacy`는 **SAC와 개념적으로 근접하나 동일한 척도가 아니다.**
  같은 구성개념이라고 기술하지 않고 **인접 증거**로 다룬다
- 수동적 사용의 영향이 사용 장면을 넘어 지속된다는 보고는
  **AI 조건을 포함하지 않는 판단(RBSE)과의 관계를 묻는 것**이 자연스러운 질문임을 시사한다.
  다만 **Lee가 역할확장 자기효능감으로의 일반화를 보인 것은 아니다**

# Limits for PlanW

- 결과변수가 Zhu의 SAC 척도가 아니다
- 글쓰기 과업 중심이며 직무 전반이 아니다
- 논문 전문을 확인하지 않았다. 설계 세부와 조건별 수치는 검색 결과에 의존
