# What the source actually studied

지연의도 기억 과제에서 **메타인지적 확신이 인지 위임 선택을 예측하는가.**
한 집단은 외부 알림 설정 방법을 명시적으로 안내받고, 다른 집단은 안내받지 않음.

# Sample / Design

MTurk 435명 모집 → 제외 후 **최종 363명.** 컴퓨터 기반 실험.

# [A] Directly Supported

- 안내받지 않은 집단도 **자발적으로** 알림을 설정했으나 안내받은 집단보다 적었다
- 위임은 양 집단 모두에서 수행을 개선했다
- **확신이 낮을수록 알림을 더 많이 설정했다. 실제 기억 능력과 무관하게 그러했다.**

# [C] PlanW Interpretation

**역방향 가능성의 근거다.**

```
PlanW 가정       DCO → SAC
Boldt & Gilbert  확신 → 위임
```

다만 **대상이 다르다** — 기억의 외부화(알림 설정)이지 판단·사고의 위임이 아니다.
[[Zhu_2026]] 의 구분으로는 **자율적 위임에 가깝다.**

  위임 행동이 변하지 않았다** → 역방향도 확립된 인과가 아니다

## 핵심 — 2.3절과 5장에서의 역할

**2.3절** — 위임을 **결정하는 요인**에 관한 연구 계보. 본 연구의 DCO 는
위임 여부가 아니라 **위임 방식**을 다루므로 층이 다르다.

**5장 한계** — **역방향 설명의 근거**다.

```
본 연구 가정    DCO → SAC
Boldt & Gilbert  확신 → 위임
```

## 5장 한계 절 문안 (초안)

> 본 연구는 횡단 설계이므로 의존적 인지위임과 독립수행 자신감의 관계에서 역방향 설명을
> 배제할 수 없다. 인지 위임 연구에서는 보조 없는 능력에 대한 확신이 낮을수록 위임을
> 더 선택한다는 보고가 있다(Boldt & Gilbert, 2019). 다만 메타인지 신념을 실험적으로
> 조작한 연구에서는 신념 변화가 실제 위임 행동의 변화로 이어지지 않았고, 자기보고된
> 전략만 달라졌다(Grinschgl et al., 2021). 본 연구의 의존적 인지위임 또한 자기보고로
> 측정되므로, 자신의 능력에 대한 평가가 위임 정도의 보고에 영향을 미쳤을 가능성을
> 배제할 수 없다.
