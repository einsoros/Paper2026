# [A] 두 구성개념의 구분

| | 정의 |
|---|---|
| **GenAI use intensity (GAIU)** | 학습 관련 과업에서 GenAI 를 **얼마나 빈번하고 폭넓게** 사용하는가 |
| **GenAI cognitive dependence (GCD)** | 아이디어 생성 · 정보 통합 · 논리 구성 · 판단 검증 등 **핵심 인지과정을 GenAI 에 외주화**하는 경향 |

저자들은 이 구분을 **연구의 중심적 구분**으로 명시한다.
**"AI 과의존은 넓게 논의되어 왔으나 행동적 사용 강도가 인지적 의존과 분리되는 경우는 드물다"**

# [A] 측정

**GAIU** — **6문항.** 과제 · 보고서 수행, 정보 요약, 개요 생성, 글 수정, 복잡한 문제 해결 등.
**앵커가 1 = never ~ 5 = always 의 빈도형.** 저자들도 frequency 와 breadth 를 함께 잰다고 적는다.

표본 N = 936. **교정표본과 검증표본 468명씩으로 분할**(seed 20250801).

# [A] 판별타당도 — 직접 검증

```
4요인 모형 (GAIU · AI 리터러시 · GCD · 지각된 학업 창의성)
  > GAIU 와 GCD 를 병합한 3요인 모형

HTMT (GAIU – GCD) = .471
Fornell-Larcker · 경쟁 측정모형 · 문항 수준 탐색적 요인분석(MLR + Geomin) 병용
모든 HTMT 값이 0.85 미만
```

**측정모형을 먼저 확립한 뒤 구조모형을 검정했다.**

# [A] 구조모형

```
GAIU → GCD                    β = .36
GCD → 지각된 학업 창의성        부적
GAIU → 지각된 학업 창의성       β = .18  (GCD · AI 리터러시 고려 후 직접 관련)
AI 리터러시 → GCD              부적
```

**명시적 매개모형이다.** H1 자체가 GAIU → GCD 이다.

# [C] PlanW Interpretation

**이 논문이 지지하는 것은 여기까지다.**

> 사용과 의존은 **관련되어 있으나 경험적으로 구별되며**, 동일 모형에서 두 변수가
> 결과변수와 **서로 다른 관련성을 나타낼 수 있다.**

**본 연구와 다른 점 셋**

```
사용 강도(빈도형 6문항)   vs   본 연구는 활용 목적(동의형 4문항, [[Zhang_Yu_Ma_2026]])
학업 맥락 · 학생 N=936    vs   직무 맥락 · 재직자 N=300
결과변수 학업 창의성       vs   수행가능성 판단(SAC · RBSE)
매개구조 GAIU → GCD → PAC  vs   병렬 IV, 인과 순서 전제하지 않음
```

**따라서 본 연구의 측정 전제는 이렇게 서술한다.**

> 학업 맥락에서 GenAI 사용과 인지적 의존이 경험적으로 구별될 수 있다는 선행 증거는 존재한다.
> 그러나 본 연구가 사용하는 [[Zhang_Yu_Ma_2026]] 의 활용 목적 척도와 [[Zhu_2026]] 의 DCO 를
> **직무 맥락의 근로자 표본에서 함께 적용했을 때에도 그 구별성이 유지되는지는
> 본 연구에서 확인할 측정 전제다.**

# Limits for PlanW — 반드시 지킬 경계

⚠️ **"사용과 의존은 다르다"를 본 연구의 기여로 주장하지 않는다.** 이미 보고되었다.

⚠️ **β = .18 을 본 연구 병렬 IV 설계의 근거로 쓰지 않는다.**
원 논문은 **명시적 매개모형**이고 H1 이 GAIU → GCD 다.
매개모형에서 직접효과가 남았다는 사실이 **인과 순서 없는 병렬 설계를 정당화하지 않는다.**
본 연구 병렬 설계의 정당화는 **횡단 자료로 인과 순서를 주장할 수 없기 때문**이며 별도 근거다.

⚠️ **"선행연구도 측정모형을 먼저 확립했다"를 본 연구 분석 순서의 방법론적 근거로 쓰지 않는다.**
사례이지 근거가 아니다. **선례와 정당화는 다르다.** → [[Writing_Notes]]

⚠️ **빈도 통제 결정을 그대로 가져오지 않는다.** Li 등의 사용 강도는 빈도 앵커를 쓰므로
중복이 개념적으로 명백했다. 본 연구의 GenAI Use 는 동의형이라 사정이 다르다.
**접근 방식(주모형 + 민감도 모형)만 참고한다.**
