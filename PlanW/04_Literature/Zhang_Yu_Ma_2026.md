# [A] GenAI Use 원척도 — 본 연구 IV1

**응답척도** 7점 리커트 (1 = strongly disagree ~ 7 = strongly agree). 전 문항 적용.

**구성** 업무 관련 GenAI 사용 / 비업무 관련 GenAI 사용 — **두 하위 구성개념**

**출처** Zhang et al.(2019) · Sun et al.(2022) 척도를 GenAI 맥락에 맞게 적응

**절차** 영중 역번역 수행. 교수 2명 · 박사과정 3명 내용타당도 검토.
교사 4명 · 대학원생 10명 파일럿.

## Table 1 (p.712) — Work-related GenAI use

```
WAU1  In my daily work, I use GenAI assistants to obtain ideas
      and participate in work-related discussion
WAU2  In my daily work, I use GenAI assistants to acquire solutions
      for work problems
WAU3  In my daily work, I use GenAI assistants in my daily work
      to ask work-related questions
WAU4  In my daily work, I use GenAI assistants in my daily work
      to get work-related knowledge
```

⚠️ **WAU3 · WAU4 의 "in my daily work" 중복은 원문 표기 그대로다.**
한국어 문항에서는 한 번만 반영했다. → [[Survey_Final]]

**신뢰도** α = 0.819 · CR = 0.881 · AVE = 0.648

# [C] PlanW Interpretation

**본 연구는 업무 관련 4문항만 사용한다.** 비업무 관련은 연구 범위 밖이다.

**측정하는 것** — 빈도가 아니라 **AI 를 어떤 인지활동에 활용하는가**(아이디어 · 해결책 · 질문 · 지식).

```
U1          얼마나 자주 쓰는가           빈도. 통제변수
GenAI Use   어떤 인지활동에 쓰는가        IV1
DCO         그 과정에서 얼마나 위임하는가   IV2
```

# Limits for PlanW

- ⚠️ **"Work-related GenAI Use(WAU)"의 한국어 명칭은 본 연구의 조작적 명명이다** → [[Writing_Notes]]
- **척도 개발 논문이 아니라 사용 연구에서 쓰인 측정**이다. 타당화 축적이 제한적이다
- 본 연구는 **7점 척도를 유지**한다. 다른 세 척도(5점)와 형식이 다르므로 화면 구현 시 주의
- ⚠️ **"선행연구는 사용량을 쟀고 본 연구는 방식을 잰다"는 대비를 이 척도에 대해 쓰지 않는다.**
  4문항은 빈도가 아니라 **사용 목적**을 묻는다 → [[Correction_Log]]
