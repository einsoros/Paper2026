# What the source actually studied

AI 사용이 비판적 사고에 미치는 영향에서 **AI 신뢰의 조절**과 **AI 리터러시의 조절된 조절**을 검토.
Cognitive Offloading Theory + Trust Calibration Theory.

# Sample / Design

- 인도 고등교육기관 · **N = 625** (연구원 215 / 교원 258 / 대학원생 152)
- 눈덩이 표집, 2025년 4~6월, KoboToolbox, 평균연령 28세
- 전 척도 5점 Likert / SPSS + PROCESS Macro Model 1, 3

# Key Findings

| 경로 | 결과 |
|---|---|
| AI 사용 → 비판적 사고 | **β = −0.31**, t = −8.45, p < .001 |
| AI 리터러시 → AI 신뢰 | β = −0.29, p < .001 |
| AI 사용 × 신뢰 → 비판적 사고 | β = −0.14, p < .001 |
| 삼원 상호작용 | β = −0.11, p < .01 |

단순기울기 — 신뢰 높을 때 β = −0.45, 낮을 때 β = −0.18
