## 자료 취급

**원자료와 식별 가능 정보는 리포에 올리지 않는다.** 분석 결과와 판단 근거만 기록한다.

외부 도구로 분석할 경우 식별 정보를 먼저 제거한다.
기관생명윤리위원회 승인 조건에 자료 취급 규정이 있으면 그것을 따른다.

## 초기 자료 점검 — 목적과 대응 원칙

본조사에 앞서 30~50명을 먼저 수집해 점검한다. 목적은 셋이다.

1. 조사도구 및 분기 로직의 정상 작동 확인
2. 응답 품질지표의 분포 확인 및 운영기준 구체화
3. 핵심 측정문항의 응답분포에 명백한 이상이 없는지 확인

| 확인 | 원칙 |
|---|---|
| 설문 · 분기 기술 오류 | 수정 후 재개. 영향받은 초기자료는 제외 |
| 응답시간 · 주의점검 지표 | 분포 확인 후 운영상 수치기준 구체화 |
| 핵심문항 응답분포 | 기술통계만 확인. 문항 · 연구모형을 변경하지 않음 |
| 표본 구성 | field 전 예상분포로 조건 결정. 시작 후 임의로 조정하지 않음 |
| H1 · RQ1 관계 | **보지 않음** |
| 설문 변경이 없는 경우 | 초기자료를 최종표본에 포함 |
| 설문 변경이 있는 경우 | 변경의 영향을 받은 초기자료는 최종분석에서 제외 |

**제외기준의 성격** — 원칙(어떤 지표를 볼지, 무엇을 불성실로 볼지)은 자료수집 전에 확정한다.
수치 기준(응답시간 하한 등)은 초기 자료의 분포를 참고하여 운영상 구체화한다.
따라서 논문에 **"자료수집 전에 사전 확정하였다"고 기술하지 않는다.**

## 분석 환경

학교 제공 SPSS Statistics 30 사용 가능. **AMOS 는 없는 것으로 확인됨.**

확인적 요인분석과 구조모형은 R 의 lavaan 등을 검토 중이며 확정하지 않았다.
5점 문항을 순서형으로 모델링할 가능성을 열어 둔다면 AMOS 만으로는 어렵다.

추정방법은 결과를 본 뒤 유리한 것을 고르지 않고, 본조사 분석 전에 방법론적 근거에 따라 원칙을 정한다.
