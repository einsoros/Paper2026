## 2. 업체 문의와 회신 (2026-11-13 문의 · 11-14 회신)

**회신 요지**

- 선별 4문항(근로 형태 · 직위 · 업무 특성 · 최근 1개월 사용)에서 조건 불충족자는 자동 종료.

- 주의점검 문항에서 "보통이다" 이외를 고른 **3명을 제외한 뒤 분석**하였다

- 원자료는 **응답 순서대로** 코드화되었다
- 오차공분산은 "적합도 개선을 위해" 설정. 문항 선정 기준은 제시하지 않았다

## 3. 원자료 파일과 대조

**분석 원자료는 업체 원자료 엑셀(300명)로 한다.** .sav(297명)는 쓰지 않는다.

| 대조 항목 (ID 기준 병합) | 결과 |
|---|---|
| 일치 ID | 297명. 엑셀에만 있는 3명은 주의점검 오답자 3명과 정확히 같다 |
| 측정문항 22개 | 불일치 0 |
| 선별 SQ1~SQ4 · 사용특성 U1~U4 | 불일치 0 |
| 배경 D1~D7 (.sav 변수명 Q1~Q7) | 불일치 0 |
| session_created_at | 불일치 0 |
| duration_seconds | **.sav = 엑셀 + 60초, 297명 전원 동일** (차이의 표준편차 0) |

대조는 회사 계정 스레드가 수행했다(2026-11-14). **60초 차이의 원인은 확인되지 않았다.**
3장에는 최종 원자료(엑셀)의 소요시간을 기술하고, 업체가 측정 정확성의 한계를 밝혔다는 점을 함께 적는다.
어느 쪽이 정확한지 단정하지 않는다.

.sav 에만 있는 변수 — Q2_변환, VAR00001~3(연령 · 조직규모 · 총경력 이분 변수),
x1 · X2 · Y1 · Y2(업체 합산점수, 업체 표기 Y1 = RBSE, Y2 = SAC). **분석에 쓰지 않는다.**

## 6. 업체 분석 결과의 지위

업체 결과(AMOS 확인적 요인분석 · 경로모형 · 다중집단분석)는 **비교용으로만** 보관한다.

- CFA 에 RBSE 문항 간 오차공분산 6쌍을 수정지수 기반으로 추가 — 계획은 2–4 · 6–7 쌍을
  잔차가 관찰될 때만 검토([[Analysis_Plan]] 199–208행). **채택하지 않는다**
- 경로모형에 통제변수 U1 · U2 없음, RQ1 · RQ2 에도 "채택" 표기 — **쓰지 않는다**
- 다중집단분석(연령 · 총경력) — 계획에 없음([[Decision_Log]] 2026-10-24 3차). **쓰지 않는다**
