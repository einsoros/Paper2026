## 3. 원자료 파일과 대조

**분석 원자료는 업체 원자료 엑셀(300명)로 한다.** .sav(297명)는 쓰지 않는다.

| 대조 항목 (ID 기준 병합) | 결과 |
|---|---|
| 일치 ID | 297명. 엑셀에만 있는 3명은 주의점검 오답자 3명과 정확히 같다 |
| 측정문항 22개 | 불일치 0 |
| 선별 SQ1~SQ4 · 사용특성 U1~U4 | 불일치 0 |
| 배경 D1~D7 (.sav 변수명 Q1~Q7) | 불일치 0 |
| session_created_at | 불일치 0 |
| duration_seconds | **.sav = 엑셀 + 60초, 297명 전원 동일** (차이의 표준편차 0) |

대조는 회사 계정 스레드가 수행했다(2026-11-14). **60초 차이의 원인은 확인되지 않았다.**
3장에는 최종 원자료(엑셀)의 소요시간을 기술하고, 업체가 측정 정확성의 한계를 밝혔다는 점을 함께 적는다.
어느 쪽이 정확한지 단정하지 않는다.

.sav 에만 있는 변수 — Q2_변환, VAR00001~3(연령 · 조직규모 · 총경력 이분 변수),
x1 · X2 · Y1 · Y2(업체 합산점수, 업체 표기 Y1 = RBSE, Y2 = SAC). **분석에 쓰지 않는다.**

## 7. 업체 변환변수 점검 — 연령대 변환 오류 (2026-11-15)

업체 .sav 의 연령대 변수 `Q2_변환`을 응답자가 직접 입력한 나이(.sav `Q2` = 엑셀 `D2`)와 대조했다.
**50명이 잘못 분류되어 있다** — 32세 7명 · 34세 13명 · 35세 19명 · 36세 11명이 40대로 변환됨.

영향받은 업체 산출물

- output.xlsx 「Sheet1」 · 「빈도」 및 보고서 4.2절의 연령 분포 — 30대 79명 / 40대 129명으로 보고.
  실제(297명)는 30대 129명 / 40대 79명. 보고서 문장 "40대가 129명(43.4%)으로 가장 많았다"는 틀림
- `VAR00001`(연령 이분, Q2_변환에서 생성) → `다중(연령)` 분석의 집단 구분. 126 / 171 → 실제 176 / 121
  → [[Structural_Model]] 2절

같은 방식으로 대조한 나머지 변환변수 — `VAR00002`(조직규모 이분), `VAR00003`(총경력 이분)은 원범주와 일치.
성별 · 직무 · 업종 · 조직규모 · 총경력 · 근속 · U1~U4 의 업체 빈도표도 297명 기준으로 원자료와 일치.

**→ 연령대는 항상 원 나이(D2)에서 나눈다. 업체 `Q2_변환` · `VAR00001` 은 쓰지 않는다.**
