## 2. 2차 추가분석 — 확인적 요인분석 (최종 측정모형)

**분석 조건** N = 297, R lavaan 0.6-17, 연속형 처리, MLR 주 추정 · ML 비교 → [[Decision_Log]] 2026-11-15.
4요인(GenAI Use 4 · DCO 4 · SAC 4 · RBSE 10). 스크립트는 연구자 로컬 보관.

**무엇을 검증했나** — 1차 통계분석의 사후 오차공분산 6쌍 없이, [[Analysis_Plan]] 「RBSE 10문항 — 오차상관 처리」
규칙만으로 네 개념이 측정되는가.

### 절차

1. 오차공분산 없는 4요인 모형(M0)을 먼저 추정
2. 원척도 사전 후보 두 쌍의 상관잔차 확인 — RBSE 문항 순서가 [[Parker_1998]] Table 1 과 같음을 대조함

| 쌍 | 문항 공통 내용 (Parker 원문) | M0 상관잔차 | 판단 |
|---|---|---|---|
| B2–B4 | management | **.31** | 관찰됨 → 허용 |
| B6–B7 | your work area | .04 | 관찰되지 않음 → 허용하지 않음 |

3. B2–B4 오차공분산 1개만 둔 모형(M1)을 최종 측정모형으로 한다

### 적합도

| 지수 | M0 (MLR) | **M1 (MLR)** | M1 (ML) |
|---|---|---|---|
| χ² (df) | 742.155 (203) | **546.037 (202)** | 587.942 (202) |
| CFI | .896 | **.934** | .931 |
| TLI | .882 | **.924** | .921 |
| RMSEA [90% CI] | .098 [.091, .106] | **.079 [.071, .087]** | .080 [.073, .088] |
| SRMR | .055 | **.055** | .055 |

MLR 의 χ² · CFI · TLI · RMSEA 는 척도보정(scaled) · robust 값. 척도보정계수 1.076(M0).
M0 → M1 Satorra-Bentler 척도보정 χ² 차이 = 251.84, df 1, p < .001.

### 적재량 · 신뢰도 · 수렴타당도 (M1, 표준화)

| 개념 | 적재량 범위 | CR | AVE | √AVE |
|---|---|---|---|---|
| GenAI Use | .828 ~ .866 | .914 | .726 | .852 |
| DCO | .753 ~ .885 | .904 | .701 | .838 |
| SAC | .806 ~ .930 | .936 | .785 | .886 |
| RBSE | .686 ~ .878 | .928 | .606 | .778 |

RBSE 최저 B4 .686. RBSE 의 CR 은 B2–B4 오차공분산을 반영해 계산했다.
B2–B4 오차상관 = .729.

### 잠재변수 상관 (M1)

| | GenAI Use | DCO | SAC |
|---|---|---|---|
| DCO | −.337 | | |
| SAC | .315 | −.683 | |
| RBSE | .622 | −.561 | .605 |

가장 큰 상관 DCO–SAC |−.683| < √AVE (.838, .886). 모든 쌍에서 Fornell-Larcker 기준 충족.

### 확정 사항

- 최종 측정모형 = M1 (B2–B4 오차공분산 1개)
- CFI = .934, TLI = .924, RMSEA = .079, SRMR = .055 로 지표별로 다소 상이한 수준의 적합도를 보였으며,
  이를 종합적으로 고려하였다. "우수" · "모든 지수 기준 충족"으로 기술하지 않는다
- 요인적재량, CR, AVE 및 Fornell-Larcker 기준은 네 구성개념의 수렴 및 판별타당도를 지지하였다.
  **최종 판별타당도 판단은 HTMT 와 경쟁모형 χ² 차이검정 후 확정한다** → 2차 추가분석 ④
- B2–B4 허용 근거 — [[Parker_1998]] 원문이 같은 문항쌍의 management 내용 중복과 오차상관을 보고(74–75행).
  원척도 근거 + 본 표본 잔차 + 큰 불일치 감소가 함께 있다
- 1차 통계분석의 사후 오차공분산 6쌍 없이도 네 요인 구조와 잠재변수 상관이 거의 같게 재현되었다
  (DCO–SAC −.683 · GenAI–DCO −.337 동일, SAC–RBSE .629 → .605)
- ML 로 추정해도 적합도 판단이 달라지지 않는다

### 해석 · 추후 확인 (확정 아님)

- B2–B4 오차상관 .729 는 크다. RBSE 외에 "경영진을 상대하는 활동"이라는 문항 특수성을 강하게 공유한다는 뜻.
  심사 질문 시 Parker 원척도 근거로 답한다
- M1 잔차 — B6(비용 지출 제안서)이 DCO 4문항과 +.12 ~ +.16, SAC 3문항과 −.11 ~ −.13.
  B1–B2(.20) · B1–B4(.15) · B7–B8(.12) · B3–B5(.11). **모형을 더 수정하지 않는다** — 특히 서로 다른 요인의 문항 간
  오차공분산은 두지 않는다. 원인은 해석 후보만 있고 근거 없음. 논문 본문 보고는 현재 계획 없음
