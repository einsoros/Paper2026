## 2. 1차 통계분석 — 사후 다중집단분석(연령 · 총경력)

### 2-1. `AMOS/다중(연령).AmosOutput` — **해석 제외**

**집단 구분 오류.** 집단 변수 `VAR00001` 은 1차 통계분석 자료의 연령대 변수 `Q2_변환`에서 만들어졌고,
`Q2_변환`은 32~36세 50명을 40대로 잘못 분류했다 → [[Collection_Log]] 7절.
1차 통계분석의 집단 "30대 이하 126 / 40대 이상 171"은 실제 176 / 121 이어야 하며, "40대 이상"의 약 29%가 30대다.
**이 출력은 연령 비교로 해석하지 않는다.** 다시 돌리지 않는다(사전 계획 분석이 아님).

참고 — 1차 통계분석 보고서의 "Δχ² = 88.461, 연령은 조절변수로서 의미가 있다"는 비제약 → 구조경로 동일 비교값이며,
이 중 72.086(df 18)은 적재량 동일 제약, 16.374(df 4)는 구조경로 동일 제약에서 나온 것이다.
집단 구분 오류와 별개로, 이 값 전체를 경로 차이(조절효과) 근거로 읽을 수 없다.

**확정** — 1차 통계분석 보고서가 제시한 연령 조절효과는 B1 핵심 결과를 확장할 근거로 사용하지 않는다.

  10년 이상 집단은 DCO 가 높고 분산이 좁다. 분산이 좁으면 상관이 약하게 나오므로,

## 3. 2차 추가분석 — 구조모형 (통제변수 없음)

측정부는 [[Measurement_Model]] 2절 최종 측정모형(M1, RBSE 오차공분산 B2–B4 1개). 통제변수 U1 · U2 는 다음 단계(③).

**무엇을 검증했나** — 확정된 측정모형 위에서, 다른 독립변수를 함께 고려한 상태로
DCO 와 GenAI Use 가 SAC · RBSE 와 각각 어떤 고유 관련성을 갖는가.

### 모형 설정

```
DCO       → SAC   (H1)        GenAI Use → RBSE  (H2)
GenAI Use → SAC   (RQ1)       DCO       → RBSE  (RQ2)
GenAI Use ↔ DCO   공분산       SAC ↔ RBSE 잔차공분산 (자유 추정)
SAC → RBSE 직접경로 없음
```

**설정 논리 (3장용)** — SAC 와 RBSE 는 서로 다른 두 결과변수이며 둘 사이에 방향 경로를 가정하지 않는다.
다만 두 결과변수에 공통적으로 작용하는 모형 외 요인의 가능성을 고려하여 잔차공분산을 허용한다.
→ [[Analysis_Plan]] "네 경로를 하나의 모형에서 동시에 추정" · "SAC → RBSE 경로 없음"과 충돌하지 않는다.

**이력 (내부 기록, 논문 본문에 쓰지 않음)** — 이 사양은 1차 통계분석에서 잔차공분산을 0으로 제약한
영향(χ² 약 33 증가, 1절)을 본 뒤 2026-11-15 에 정했다. → [[Decision_Log]] 2026-11-15 「이미 본 것」

### 확정 사항

- **H1** — DCO 는 SAC 와 강한 부적 관련성을 보였다 (β = −.650, p < .001)
- **H2** — GenAI Use 는 RBSE 와 정적 관련성을 보였다 (β = .489, p < .001)
- **RQ2** — DCO 는 RBSE 와 부적 관련성을 보였다 (β = −.396, p < .001)
- **RQ1** — GenAI Use 와 SAC 의 추정 관계는 작고 정(+)의 방향이나 통계적으로 유의한 관련성이 확인되지 않았다
  (β = .096, 95% CI [−.016, .207], p = .093).
  1차 통계분석과 효과 추정치는 유사했으며(.108 대 .096), 유의성 판단만 분석 사양에 따라 .05 경계를 오갔다
- SAC 와 RBSE 에는 두 예측변수로 설명되지 않는 공유변동이 존재한다 (잔차상관 .362, p < .001).
  0 으로 제약하면 적합도가 유의하게 악화된다
- 위 판단은 MLR · ML 어느 추정에서도 같다

### 기술 원칙 (3 · 4 · 5장)

- RQ1 — "관계가 사라졌다" · "기각" · "관련 없음"으로 쓰지 않는다. **비유의성은 관계 부재가 아니다**
- 잔차상관 — "제3의 변수가 있다"로 쓰지 않는다. 원인은 측정하지 않았다.
  "두 결과변수에는 현재 모형의 두 예측변수로 설명되지 않는 공유변동이 존재한다"까지
- 구조모형 적합도로 연구모형을 "지지"했다고 쓰지 않는다 (포화 구조)
- 3장은 설정 논리, 4장은 잔차공분산 유의성과 0 제약 시 악화 — 순서를 섞지 않는다
- "DCO 가 중요하고 GenAI Use 는 중요하지 않다"로 확장하지 않는다 — RBSE 에서는 GenAI Use 가 β = .489

### 4장 문안 초안 (통제변수 결과 반영 전)

> DCO 는 SAC 와 강한 부적 관련성(β = −.650, p < .001)을, RBSE 와도 부적 관련성(β = −.396, p < .001)을 보였다.
> GenAI Use 는 RBSE 와 정적 관련성(β = .489, p < .001)을 보였으나, SAC 와의 관련성은 작고 통계적으로 유의하지
> 않았다(β = .096, p = .093). 두 예측변수는 SAC 변동의 47.4%, RBSE 변동의 52.6% 를 설명하였다.
> 두 결과변수의 잔차 간에는 유의한 정적 상관이 남았다(r = .362, p < .001).
