- CFA 대비 추가된 제약 1개가 이 잔차공분산 제약이며, 이와 함께 χ² 가 444.890 → 477.935(약 33.05) 증가했다

### 해석 · 추후 확인 (확정 아님)

- 같은 AI 사용이라도 활용 목적(GenAI Use)과 의존적 위임(DCO)은 두 판단과 반대 방향으로 관련된다 —
  B1 이 보려던 구분과 일관된 결과 [C]
- RQ1 은 유의하나 β = .108 로 다른 세 경로보다 작다
- SAC–RBSE 잔차공분산을 자유롭게 추정하면 적합도가 개선될 가능성이 높다 [C].
  잔차공분산은 SAC → RBSE 경로와 다르다 — 경로는 [[Analysis_Plan]] 에서 두지 않기로 함
- 설명력(R²)은 출력에 없다. 계수와 독립변수 상관으로 계산한 근사치 RBSE 약 .56, SAC 약 .50 —
  **확정 결과로 쓰지 않는다**. 필요하면 AMOS Squared Multiple Correlations 옵션으로 직접 출력 [GAP]
- 통제변수 U1 · U2 를 넣었을 때 네 경로가 유지되는지는 확인 전 → [[Analysis_Plan]] 2절

## 2. 1차 통계분석 — 사후 다중집단분석(연령 · 총경력)

1차 통계분석에 사후로 추가된 분석이며 [[Analysis_Plan]] 의 가설 검증에는 포함되지 않는다.

### 2-1. `AMOS/다중(연령).AmosOutput` — **해석 제외**

**집단 구분 오류.** 집단 변수 `VAR00001` 은 1차 통계분석 자료의 연령대 변수 `Q2_변환`에서 만들어졌고,
`Q2_변환`은 32~36세 50명을 40대로 잘못 분류했다 → [[Collection_Log]] 7절.
1차 통계분석의 집단 "30대 이하 126 / 40대 이상 171"은 실제 176 / 121 이어야 하며, "40대 이상"의 약 29%가 30대다.
**이 출력은 연령 비교로 해석하지 않는다.** 다시 돌리지 않는다(사전 계획 분석이 아님).

참고 — 1차 통계분석 보고서의 "Δχ² = 88.461, 연령은 조절변수로서 의미가 있다"는 비제약 → 구조경로 동일 비교값이며,
이 중 72.086(df 18)은 적재량 동일 제약, 16.374(df 4)는 구조경로 동일 제약에서 나온 것이다.
집단 구분 오류와 별개로, 이 값 전체를 경로 차이(조절효과) 근거로 읽을 수 없다.

**확정** — 1차 통계분석 보고서가 제시한 연령 조절효과는 B1 핵심 결과를 확장할 근거로 사용하지 않는다.

### 2-2. `AMOS/다중(총경력).AmosOutput`

**분석 조건** 집단 변수 `VAR00003` — Group 1 = 총경력 10년 미만 211명, Group 2 = 10년 이상 86명.
원범주(D6)와 일치함을 확인했다. 개 · 헷이 각각 원본을 읽고 대조했다(2026-11-15).

**모형 비교** — 다중(총경력).AmosOutput, Model Comparisons · Model Fit Summary

| 비교 | Δχ² (df) | p | 비고 |
|---|---|---|---|
| 비제약 → 적재량 동일 | 35.546 (18) | .008 | CFI .941 → .937 (ΔCFI .004), RMSEA .052 → .052 |
| 적재량 동일 → 구조경로 동일 | 6.674 (4) | .154 | |
| 구조경로 동일 → 구조공분산 동일 | 15.613 (3) | .001 | 묶인 3개 = DCO 분산 · GenAI Use 분산 · 둘의 공분산 |
| 1차 보고 (비제약 → 구조경로 동일) | 42.220 (22) | .006 | 보고서 본문은 "p < .001"로 잘못 기재 |

비제약 다중집단모형 적합도 χ² = 712.963 (df 396), CFI .941, RMSEA .052.

**집단별 표준화 계수** — Standardized Regression Weights (Unconstrained)

| 경로 | 10년 미만 (211) | 10년 이상 (86) |
|---|---|---|
| H1 DCO → SAC | −.688 | −.341 (p = .007) |
| RQ2 DCO → RBSE | −.504 | −.165 (p = .129) |
| H2 GenAI Use → RBSE | .469 | .523 |
| RQ1 GenAI Use → SAC | .124 (p = .032) | .044 (p = .700) |

**확정**

> 총경력 10년 미만(n = 211)과 10년 이상(n = 86)을 비교한 사후 다중집단분석에서 집단별 표준화 경로계수에는
> 일부 차이가 관찰되었으나, 네 구조경로에 동일성 제약을 부과해도 모형 적합도는 유의하게 악화되지 않았다
> (Δχ² = 6.674, Δdf = 4, p = .154). 따라서 총경력에 따른 구조경로 차이를 지지하는 통계적 근거는 확인되지 않았다.

- 한 집단에서 유의하고 다른 집단에서 유의하지 않다는 것은 계수 차이의 근거가 아니다
- 1차 통계분석 보고서의 "총 경력은 조절변수로서 의미가 있다"는 경로 차이 근거로 성립하지 않는다
- 4장 핵심 결과 · 5장 한계에 넣지 않는다. 사후 추가분석으로 보관

**해석 · 추후 확인 (확정 아님)**

- 10년 이상 집단은 86명이라 표준오차가 크다(DCO → SAC 비표준화 S.E. .329 대 .141). 경로가 같다고 단정할 수도 없다
- 구조공분산 단계의 차이는 경로가 아니라 독립변수 분포의 차이다. 원자료(297명) 기술통계로 보면
  DCO 평균 2.93 (SD .86) 대 3.81 (SD .61), GenAI Use 평균 4.25 (SD 1.59) 대 3.56 (SD 1.46).
  10년 이상 집단은 DCO 가 높고 분산이 좁다. 분산이 좁으면 상관이 약하게 나오므로,
  이 집단에서 DCO 경로가 약해 보이는 것과 연결될 수 있다 [C]
- 집단별 기술통계는 보고할 수 있으나 차이의 증거로 해석하지 않는다 → [[Analysis_Plan]] 373–391행
