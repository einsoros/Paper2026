## 2.3 인지적 오프로딩 연구와 자기 능력 판단

**역할** — **이 장의 핵심.** DCO–SAC 축의 이론적 배경. 고리 ②.

```
[[Risko_Gilbert_2016]]       CO 정의와 메타인지 모형 (Figure 3)
                             외부화 경험 ↔ 내부 능력에 대한 메타인지적 평가의 순환
                             경계 흐림 연구 — "외부 자원 없이도 더 잘할 것"이라는 예측
[[Boldt_Gilbert_2019]]       확신 → 위임 선택 (화살표 A 쪽)
[[Grinschgl_2021_PsyRes]]    신념 조작 → 행동 불변, 자기보고만 변화
```

**흐름**

```
① CO 란 무엇인가 — 물리적 행위를 통한 인지 부담 경감
② 그런데 CO 연구는 일찍부터 메타인지 문제를 함께 다루었다
   외부 자원 사용은 자기 능력 평가의 영향을 받고,
   반대로 그 경험이 이후의 자기 능력 평가를 바꿀 수 있다
③ 생성형 AI 는 이 문제를 새로운 형태로 제기한다
   위임되는 것이 저장 · 계산이 아니라 사고 · 구조화 · 판단이기 때문이다
④ 따라서 본 연구는 DCO 를 CO 의 하위개념이 아니라
   같은 연구문제를 새 환경에서 만나는 별도 구성개념으로 다룬다
```

⚠️ **"CO 의 범위를 좁힌 것"이라고 쓰지 않는다.** → [[Risko_Gilbert_2016]] 경계 항목

## 2.4 자기효능감과 수행가능성 판단

**역할** — 두 종속변수의 이론적 토대. 고리 ①.

```
Bandura (1977)            효능 기대 vs 결과 기대 (p.193)
                          네 원천, 그중 수행 성취 (p.195)
                          "개인의 숙달 경험"이라는 조건
Gist & Mitchell (1992)    조직 맥락으로의 확장   ← 확보 완료, 노트 미작성
```

**흐름**

```
① 효능 기대는 결과 기대와 구별된다 — 할 수 있는가 vs 하면 무엇이 되는가
② 효능감은 영역특정적이다
③ 수행 성취가 가장 영향력 있는 원천인 이유는 "개인의 숙달 경험"이기 때문이다
④ [본 연구의 문제제기] AI 와 함께 수행한 성공이 이 조건에 어떻게 해당하는가
```

⚠️ **④ 는 Bandura 의 주장이 아니라 본 연구의 추론**임을 명시한다.
⚠️ **본 연구는 숙달 경험을 측정하지 않는다.** 기제로만 서술한다. → [[Mechanism_Status]]

## 2.7 활용과 위임을 구별하는 것

**역할** — 고리 ③의 뒷부분. **B1 의 측정 전제를 여기서 선언한다.**

```
[[Li_2026]]              사용 강도와 인지적 의존의 경험적 구별. HTMT = .471
[[Risko_Gilbert_2016]]   자동화 연구의 문제의식   ← 배경으로만
```

**흐름**

```
① 기술적 지원의 정도만으로 인지적 결과가 결정되지 않는다 (배경)
② 사용과 의존이 경험적으로 구별될 수 있다는 선행 증거가 있다 ([[Li_2026]])
③ 다만 Li 등은 학업 맥락이고 사용 강도는 빈도형 척도다
④ [측정 전제 선언] 본 연구는 직무 맥락에서 활용 목적 척도와 DCO 를 함께 적용한다.
   구조적 관계를 검토하기에 앞서 측정모형을 통해 두 구성개념의
   경험적 구별성을 확인한다
```

⚠️ **"사용과 의존은 다르다"를 본 연구의 기여로 주장하지 않는다.**
⚠️ **새로운 연구질문(RQ3)으로 올리지 않는다.** 측정 전제다. → [[Decision_Log]] 2026-10-24

## 2.10 두 수행가능성 판단을 함께 보는 것

**역할** — 고리 ①의 결론. **왜 이 두 기준점인가.**

```
Bandura (1977)   효능감의 영역특정성
[[Zhu_2026]]     SAC — 지원조건을 특정 (AI 가 없을 때)
[[Parker_1998]]  RBSE — 역할범위를 특정 (현재 역할을 넘어설 때)
```

**흐름**

> AI 병행 업무에서 수행가능성 판단이 흔들릴 수 있는 지점은 두 가지다.
> 하나는 **지원조건**, 다른 하나는 **역할범위**다.
> 둘은 서로 다른 조건을 특정하므로, 함께 관찰할 때
> **같은 사용 방식이 어느 기준점의 판단과 연결되는지**를 구별할 수 있다.

⚠️ **"capability 의 두 대표 차원"이라고 쓰지 않는다.** 하나의 상위 잠재변수로 묶지 않는다.
⚠️ **서로 다른 방향으로 움직일 것을 전제하지 않는다.**

## 2.11 가설과 연구질문의 도출

```
[[Ye_2026]]        의존 → 일반 직무 자기효능감. 다출처 시차 + 실험
[[Lee_2026]]       수동적 의존 → AI 부재 조건 자기효능감. 사전등록 실험
[[Shojaei_2026]]   의존 안에 독립수행 자신감을 혼재 측정한 사례
```

**네 경로의 도출**

| | 도출 근거 |
|---|---|
| **H1** DCO → SAC (−) | [[Zhu_2026]] 주체성 전이 · [[Lee_2026]] 실험. **확인적 성격** |
| **H2** WAU → RBSE (+) | [[Zhang_2026]] β = .347. **재현의 성격** |
| **RQ1** WAU → SAC | 정(+) — [[Brynjolfsson_2023]] 학습 효과 / 부(−) — Zhu 기제의 확장. **양쪽 가능** |
| **RQ2** DCO → RBSE | 부(−) — 주체성 전이의 일반화 / 정(+) — 확장된 역량의 증거. **경쟁 예측** |

⚠️ **"선행연구가 없어서 RQ"가 아니라 "경쟁하는 이론적 예측이 실재해서 RQ"** 다.
**양쪽 논리를 모두 제시**한 뒤 방향을 열어 둔다.
