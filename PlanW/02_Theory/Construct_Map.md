# 구성개념 지도

> **섞지 않기 위한 문서다.** 집필 중 용어가 흔들리면 여기로 돌아온다.

## 예측변수 쪽 — 다섯이 서로 다르다

| 구성개념 | 무엇을 재는가 | 출처 |
|---|---|---|
| **AI 사용량 · 빈도** | 얼마나 자주 쓰는가 | PlanW의 U1, **통제변수** |
| **GenAI Use** | 아이디어 · 해결책 · 지식 · 질문 등 **업무상 인지활동에 활용하는 정도** | [[Zhang_2026]] 4문항, **PlanW의 IV1** |
| **AI 의존 · 기능적 의존** | AI가 **대체하기 어려운 핵심 채널**이 되었는가 | [[Ye_2026]] |
| **DCO 의존적 인지위임** | 과업 안에서 **사고와 판단을 AI에 넘기는 방식** | [[Zhu_2026]], **PlanW의 IV2** |
| **수동적 의존** | AI 산출물을 최소 수정으로 수용하고 인지 작업을 맡김 | [[Lee_2026]] 5문항. **DCO와 내용이 대응** |
| **능동적 협업** | AI 산출물을 비판적으로 평가 · 수정하고 최종 결정권 유지 | [[Lee_2026]] 6문항. **AO와 사실상 같음** |
| **AO 자율적 인지위임** | AI를 발판으로 쓰며 **최종 산물의 소유를 유지** | [[Zhu_2026]] |
| **AI에 대한 능동적 피드백** | AI 결과를 평가 · 수정하고 최종 결정권을 유지 | [[Ye_2026]] |

**주의할 점**

- [[Zhu_2026]] 은 DCO가 **사용빈도와 무관**하다고 명시한다. 많이 써도 자율적일 수 있다
- **GenAI Use ≠ 사용량.** [[Zhang_2026]] 4문항은 **무엇에 쓰는가**를 묻는다
- ⚠️ **"Work-related GenAI Use(WAU)"는 본 연구의 조작적 명명이다.**
  [[Zhang_2026]] 원문 명칭은 **"GenAI use"** 이며 "work-related"는 원문에 없다
- ⚠️ [[Lee_2026]] 의 수동 · 능동은 **상관 r = −.597 이나 단일 양극 척도가 아니다.**
  별도 변수로 측정되었다. "Lee는 한 축, 본 연구는 두 축"이라는 대비를 쓰지 않는다
- **AI 의존 ≠ DCO.** 전자는 **상태**, 후자는 **수행 방식**이다. 인접하나 동일하지 않다
- **능동적 피드백은 AO와 개념이 가깝다.** 조절변수로 가져오면
  "의존적 위임 × 자율적 사용"이 되어 꼬인다 → 사용하지 않는다
- **DCO와 AO를 하나의 양극 척도로 기록하지 않는다.** Zhu에서 별도 구성개념이다

## 결과변수 쪽 — 넷이 서로 다르다

| 구성개념 | 무엇을 재는가 | 출처 |
|---|---|---|
| **객관적 수행 · 숙련도** | 실제로 얼마나 잘하는가 | **본 연구 범위 밖** |
| **일반 직무 자기효능감** | 일을 잘할 수 있다고 느끼는가 | Chen et al.(2001), [[Ye_2026]] 사용 |
| **SAC 독립수행 자신감** | **AI 없이** 유사 과업을 할 수 있다고 느끼는가 | [[Zhu_2026]], **PlanW의 DV1** |
| **AI-independent self-efficacy** | AI 도구 없이 유사 과업을 수행할 수 있다고 느끼는가 | [[Lee_2026]] 3문항. **SAC와 reference가 같음** |
| **RBSE 역할확장 자기효능감** | **기존 역할을 넘어** 더 넓은 역할을 할 수 있다고 느끼는가 | [[Parker_1998]], **PlanW의 DV2** |

**주의할 점**

- **DCO를 실제 능력 상실로 정의하지 않는다.** 수행 방식을 재는 것이다
- **SAC는 객관적 수행능력이 아니다.** 자기판단이다
- [[Ye_2026]] 의 일반 직무 자기효능감과 SAC는 다르다. **Ye 저자가 직접 구분했다**
- SAC와 RBSE의 차이는 **AI 조건이 아니라 과업 범위**다.
  SAC는 "같은 일을 혼자", RBSE는 "다른 일까지"

## 네 층위 요약

```
사용량       AI를 얼마나 쓰는가              U1 — 통제
활용 범위     어떤 인지활동에 쓰는가           GenAI Use — IV1
위임 여부     위임할 것인가 말 것인가          Boldt · Grinschgl
위임 방식     어떻게 위임하는가               DCO — IV2
자기판단      할 수 있다고 느끼는가            SAC · RBSE — DV
실제 수행     실제로 할 수 있는가             범위 밖
```

**PlanW 는 활용 범위(IV1)와 위임 방식(IV2)을 분리하여,
두 reference 의 자기판단(DV1 · DV2)과의 관련을 각각 본다.**
