## 작성 원칙

**[A] 와 [C] 를 구분한다.** 원저자가 주장한 것과 본 연구의 해석을 섞지 않는다.

**모형과 연결되는 문헌만 넣는다.** 분량을 위해 문헌을 쌓지 않는다.
조사 과정에서 알게 된 것을 전부 쓰지 말고, 연구모형을 설명하는 데 필요한 것만 본문에 남긴다.

**상위 이론의 역할을 넘지 않는다.** Social Cognitive Theory 와 Gist & Mitchell(1992) 은
수행가능성 판단을 다룰 수 있는 골격을 제공할 뿐, DCO → SAC/RBSE 의 방향을 직접 예측하지 않는다.
