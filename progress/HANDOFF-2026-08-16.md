## 2. 연구 개요

```
[배경 전제] AI-인간 협업 환경 (IT 개발직 — 샘플링으로 통제)

[IV 조작]  성과 기여 귀속 모호성  (귀속 명확 vs 귀속 모호, 시나리오 2조건)
              │ H1  귀인이론 기대원리 (Weiner 1985)
              ▼
[MV 측정]  지각된 평가 불확실성
              │ H2 / H3(매개)  UMT (Van den Bos 2001)
              ▼
[DV 측정]  절차공정성 지각 (consistency + bias suppression, Colquitt 2001)
              ▲
              │ H4  MV→DV 경로(b-경로) 조절 · PROCESS Model 14
[MOD 측정] 평가 절차 명확성 (Erdogan 2002)
```

**핵심 문제의식** (`research-model.md` 확정본, `logic-architecture.md`와 동일)

> AI-인간 협업 환경에서 자기 기여 경계를 설명하기 어려워질수록, 평가 대상자는 자신이 어떻게 평가될지 예측할 수 없게 되고, 이 불확실성이 기존 평가 시스템의 절차공정성을 낮게 지각하게 만든다. 조직이 평가 절차를 명확히 설명하면 이 불확실성이 절차공정성 지각을 낮추는 정도는 완화될 수 있으나, 기여 경계의 불명확성에서 비롯된 불확실성 자체가 사라지는 것은 아니다. 즉 이 현상은 평가 시스템 자체의 결함이 아니라 산출물에서 기여가 분리되기 어려운 성질에 기인한 인식 조건의 문제이며, 따라서 절차를 개선하는 방식만으로는 그 원인에 닿지 못한다.

**확정 상태** — IV·MV·DV·MOD 정의·문항·조작 전부 확정. MOD 문항만 재설계 중(§A2). H4 존치 확정(08-13). 표본 목표 **250**(H4 상호작용 기준).

## 4. ★ 지금 가장 중요한 것 — 척도 절차 이슈 8건

`action-items-260816.md` §「[08-16] 척도 개발 절차 원문 대조」에 전문.

### 🔴 I2 — DV(Colquitt) 재작성 (미해결, 최우선)

`Literature_Map` 223행이 DV를 *"원문항 번역이 아니라 **기준 재작성**"*으로 규정했는데, 이는 Heggestad Table 6의 **「Changes to item wording」**에 해당한다. 그 범주가 가장 엄격하다.

```
minor (명확성·가독성 개선)  → 추가 타당도 증거 불필요 → 해결
substantive               → T1-T2 분할 투여 설계 필요 → 현 타임라인 밖 → 문제
```

**해야 할 일**: `measurement-items` §III의 DV 4문항 ↔ Colquitt(2001) 절차공정성 7문항 원문 **1:1 대조 후 판정**. Colquitt 원문은 Zotero `03_Model_Hypotheses/DV_Procedural_Justice` 확인.

⚠️ MOD(Erdogan 기반 재설계)도 같은 판정이 필요하다 → §A2 선행 결정에 추가.

### 🔴 I1 — MV 측정모형 형식 (해결 방향 확인됨)

MacKenzie Step 4. 판단 질문 3개에 답해 문서화만 하면 된다.

```
① D1·D2는 MV의 발현인가, 정의적 특성인가
② MV는 D1·D2보다 깊은 수준에 따로 존재하는가, 둘의 함수인가
③ MV가 변하면 D1·D2가 함께 변하는가, 하나만 변해도 되는가
```

검토 결과 **reflective**로 보이며, 그러면 `analysis-plan`의 CFA·AVE·α·4문항·Model 14 단일 점수가 전부 그대로 유효하다(연쇄 변경 없음).

2차 결정: D1·D2를 2차 요인으로 둘지 1요인 4문항으로 둘지. **하위 요인당 2문항이라 2차 요인은 CFA 식별이 불안정 → 1요인 권고**, D1·D2는 내용영역 구분으로만.
