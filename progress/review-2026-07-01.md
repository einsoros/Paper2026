# Review 2026-07-01 — 윤지환 계열 학위논문 3편 분석

> V17(척도 국내 검증본 확보) · V18(이론 KCI 재인용) 재편 방향의 실물 근거를 확보한다.

## 0. 이번 세션에서 바로잡은 사실관계

- "김민준" → 실제 **김영준** (26 박사, 조직공정성). 파일명 기준 정정.
- "24석사 김민경" → 실제 **24 박사** (박사논문이라 조절된 매개·혼합연구로 구조가 더 정교함).
- "김진협: 혁신행동" → 실제 DV는 **개인 성과**(파일명·본문 기준).

## 2. 편별 요약

### 김진협 (26석사, PMS)
- **구조**: 표준 5장. Ⅱ장 말미 "연구 공백" 절로 신규성 위치 명시. Ⅴ장 이론/실무 시사점 분리.
- **모형**: 순수 매개 (조절변수 없음). PMS 설계요소 → 인지요인(자기효능감·성과기대·자기조절) → 개인성과.
- **방법**: PLS-SEM (Python). EFA → Cronbach's α → CR·AVE·Fornell–Larcker → VIF·R²·f²·예측력.
- **척도**: 5점 Likert, 해외 원저 "참고하여 구성". 자기효능감 = Chen et al.(2001).
- **참고문헌**: **국문 1 / 해외 72** (국문 1.4%). 유일 국문 = 최문기·손성진(2018), 『한국행정논집』 30(2).

### 김민경 (24박사, 임파워링 리더십)
- **구조**: 표준 5장 + 설명적 순차 혼합연구(정량 → 심층면접 해석 보강).
- **모형**: **조절된 매개**. 임파워링 리더십 → 자기효능감·번영감(매개) → 개인적 양면성, 조절 = 포용적 조직분위기 (표 Ⅳ-7).
- **방법**: CB-SEM CFA (CFI .920, TLI .917, RMSEA .042) + **PROCESS 매크로** + 정성. n=436.
- **척도**: 5점 Likert, 해외 원저 "번안하여 사용". 임파워링 = Arnold et al.(2000)/Srivastava et al.(2006), 자기효능감 = Chen et al.(2001), 포용분위기 = Nishii(2013) 축약 15문항.
- **참고문헌**: **국문 39 / 해외 260** (국문 13%).

### 김영준 (26박사, 조직공정성) — DV 직결
- **구조**: 5장, 다변수 모형. 조직공정성(분배·절차·상호작용) IV, WLB·조직유효성·직무소진 매개, 상사신뢰·회복탄력성 조절.
- **방법**: SPSS 25.0. EFA(주성분+Varimax) → Cronbach's α → **Baron & Kenny(1986) + SPSS PROCESS 부트스트래핑** → **위계적 회귀**(조절). n=300 (500인+ 기업, 세대별 균등, 1·2차 분리로 동일방법편의 통제).
- **척도**: 조직공정성 16문항 → 2문항 제외 → 14문항, 3요인(설명력 77.7%), 5점. 부록 문항은 국문 전통 문항체.
  - ⚠️ **척도 출처 한 줄(누구·몇 년)은 측정도구 표에서 직접 확인 필요** (텍스트 추출로 미포착).
- **참고문헌**: **국문 155 / 해외 171** (국문 48%). 한광현(2006, 조직공정성) 등 국문 KCI 재인용 경로 실재.

## 3. 종합 비교

| 항목 | 김진협 | 김민경 | 김영준 |
|---|---|---|---|
| 모형 | 순수 매개 | 조절된 매개(혼합) | 다중매개 + 조절 |

| 척도 출처 | 해외원저 참고구성 | 해외원저 번안 | 국문 전통 문항체 |
| 국문/해외 참고문헌 | 1 / 72 (1.4%) | 39 / 260 (13%) | 155 / 171 (48%) |

## 4. 결론 3

1. **"연구실 인용 관행"은 단일하지 않다.** 국문 비율 1.4% → 13% → 48%로 극단적으로 벌어짐. 계열 고유 비율이 있는 게 아니라 **주제가 국내 전통 주제(조직공정성)일수록 국문 인용이 급증**하는 패턴. → 단일 규칙("우리는 국문 몇 %")으로 잡지 말 것.
2. **김영준 = 내 인용 전략 롤모델.** DV(절차공정성)를 국문 문헌 중심(48%)으로 다룬 계열 내 논문. V17/V18의 절차공정성 국문 척도·재인용 경로는 김영준의 참고문헌·측정도구 표에서 캐내는 게 최단 경로.
3. **방법론은 PROCESS로 수렴.** H4가 PROCESS Model 14 → 계열 내 두 편(김민경·김영준)이 이미 PROCESS로 (조절된) 매개 검증. PLS-SEM(김진협)보다 시나리오 실험(집단 조작 IV)+조절된 매개 설계에 자연스러움. 김민경 표 Ⅳ-7 = 서술 템플릿, 김영준 Baron&Kenny+부트스트래핑 = 검증 논리.

## 5. 한계 (명시)

- 세 편 모두 **학위논문**. 연구실 철학의 진짜 대상인 **KCI 저널 게재본 관행은 직접 관찰 못 함.** 김영준 국문 48%는 근접 대리지표일 뿐.
- 구조적 정교함(김민경·김영준)은 참고하되, 김영준의 **다변수 복잡 모형은 차용 금지** — 내 4구성개념 모델(V16)은 간결함이 강점.

## 7. 열린 질문

- 조절변수 위치 차이: 김민경은 IV 맥락 전반 조절, 내 H4는 MV→DV 경로 국한(Model 14). 결과표에서 보고할 조건부 간접효과 경로가 다름 — 그대로 차용 불가.
- 내 MV(심리적 무력감)의 국문 척도: 임파워먼트(Spreitzer 1995) 계열의 국문 검증본을 계열 논문에서 찾을 수 있는지 (김민경은 자기효능감·번영을 매개로 써서 직접 대응은 아님).
