## 2. ★★ 통찰 — 치명으로 보였던 것의 절반은 검색 실패였다

오전에 I2를 「🔴 치명·미해결」로 올린 근거는 *"DV가 Heggestad의 가장 엄격한 범주에 자기를 분류했고, substantive면 T1-T2 분할 투여가 필요해 타임라인 밖"*이었다. 오후에 확인해 보니 **필요한 것이 전부 이미 손에 있었다.**

| 「없다」고 판단한 것 | 실제 위치 |
|---|---|
| Colquitt 원문항 → *"Zotero에서 확보 필요"* | **`Sources/Papers/Colquitt (2001)...md` 「인용 6」에 Table 1 items 3·4·5가 원문 그대로** |
| DV 척도를 무엇으로 할지 → *"탐색 필요"* | **`progress/candidate-sources.md` 46행에 이미 결정** — *"절차공정성 척도 → Niehoff & Moorman(1993) 직접 인용"* |
| Leventhal(1980) → *"PDF 미확보·간접 인용"* | **Zotero에 실물 있음** (`leventhalPcWHATSHOULD`). `paper-feature-matrix` 28행 기록이 낡았던 것 |
| Erdogan·Levy&Williams·Lyu → *"확보 필요"* | **넷 다 Zotero에 PDF 첨부까지 완비** |

### 원인은 판단력이 아니라 색인 구조

실제 서지 정보가 **세 곳에 흩어져** 있고, 셋 중 어느 것도 `HANDOFF` §7 파일 지도에 없었다.

```
paper-feature-matrix.md    ← 서지 인벤토리 (last-updated 08-09, 낡음)
Sources/Papers/            ← 원문 인용 발췌 (여기에 원문항이 있었다)
progress/candidate-sources.md  ← 문헌 채택 결정 (여기에 답이 있었다)
```

오전에 Heggestad 원문을 대조할 때 `candidate-sources.md`를 열었으면 **I2 자체가 발생하지 않았다.**

### ⚠️ 그렇다고 대조가 헛일이었던 것은 아니다

이 통찰이 *"괜히 했다"*로 기울면 곤란하다. 대조 없이는 나오지 않았을 것이 셋 있다.

1. **DV2는 실제로 신규였다.** 「이미 결정돼 있었다」가 문항 수준의 정합까지 보장하지 않았다
2. **Moorman(1991)이 원전**이라는 사실 — N&M p.537을 읽지 않으면 알 수 없다. **Rizzo와 같은 함정이 실제로 하나 더 있었다**
3. **「6규칙 중 하나만 충족해도」** 원전 문장 — 지금까지 순환 위험과 연구 범위로만 방어하던 논거에 원전이 붙었다

**즉 오늘의 교훈은 「대조하지 말라」가 아니라 「대조 전에 리포부터 뒤져라」다.**

## 4. ★ 문헌 계보의 반복 구조 — 「통용 인용처는 원전이 아니다」

오늘 같은 구조가 **두 번째로** 나왔다.

```
[MV] 통용: Rizzo 역할 모호성 6문항  → 실제 원전 정의는 (1)·(2) 두 축, (1)은 탈락
[DV] 통용: Niehoff & Moorman(1993) → 실제 원전은 Moorman(1991)  ⬜ 미확보
[MOD] 통용: Erdogan(2002)·Erdogan et al.(2001) → due process 원전은 Folger et al.(1992)  ⬜ 미확보
```

**세 구성개념 모두 같은 함정을 갖고 있다.** MV는 08-09에 뚫었고, DV는 오늘 뚫다 말았고(Moorman 미확보), MOD는 아직 손대지 않았다.

→ **작업 원칙에 추가할 것** — 척도를 채택할 때 *"이 논문이 척도 출처를 어디로 표기하는가"*를 Method 절에서 먼저 확인한다.

### 오늘 확인한 대로라면 Moorman(1991)이 DV2를 풀 수 있다

N&M p.537에 *"we added items … and deleted items that seemed to stray from the intended constructs"* — **문항 가감을 명시**한다. 원척도가 더 컸다는 뜻이고, consistency 문항이 2개였을 가능성이 실재한다. **Rizzo에서 「탈락 문항 복원」 논거를 세운 것과 정확히 같은 구조가 반복될 수 있다.**
