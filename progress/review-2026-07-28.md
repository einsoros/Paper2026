> 두 부분으로 구성. §1~7 = 모델을 어떻게 이해·설명하는가(프로포절 서론 뼈대·미팅 대본).

## 1. 모델 전체 설명문 (구두 대본)

> AI 결합 환경에서 개발자는 자기 기여를 분리해 식별하기 어려운 **귀속 모호성**을 겪는다 (IV).
> 귀인이론의 기대원리에 따르면 사람은 성과의 원인을 자신에게 귀속할 수 있을 때 미래 평가를 예측할 수 있는데, 이 특수 조건에서는 그 귀속이 깨져 **어떻게 평가받을지 예측할 수 없는 불확실성**이 형성된다 (MV).
> UMT(불확실성 관리 이론)에 따르면 사람은 평가가 불확실할수록 절차가 공정한지를 더 예민하게 따지게 되므로, 이 불확실성은 결국 **평가 시스템의 절차적 공정성에 대한 신뢰 저하**로 이어진다 (DV).
> 나아가 조직이 평가 절차를 명확히 설명하는 정도(MOD)에 따라, 불확실성이 절차공정성 신뢰를 떨어뜨리는 정도가 달라진다 (H4, 조절).

## 2. 경로별 이론 적용

| 경로 | 이론 | 이론이 말하는 한 줄 |
|---|---|---|
| IV → MV | 귀인이론 기대원리 (Weiner) | 원인을 귀속한 만큼 미래를 예측한다 → 귀속 불가 시 예측 불가 |
| MV → DV | UMT (Van den Bos) | 불확실할수록 절차 공정성을 더 따지고 → 신뢰가 흔들린다 |
| DV 측정 | 절차공정성이론 (Colquitt) | consistency + bias suppression으로 측정 |

**핵심 원칙:** 이론은 정상 상태가 아니라 '깨지는 조건'을 설명해야 한다. 귀인이론을 "귀속되면 예측된다"(정상)로 끝내지 말고 "AI 협업으로 귀속이 깨져 예측 불가"(특수 조건)까지 가야 IV→MV가 이어진다.

## 3. 순환 차단 — MV와 DV는 다른 것

| | 무엇인가 | 상태 |
|---|---|---|
| MV | 내가 어떻게 평가받을지 **예측할 수 없다** | '모름' (평가 결과 예측) |
| DV | 이 절차가 일관·공정한지 **못 믿겠다** | '불신' (절차 평가) |

- 순서는 **불확실(모름) → 불신(못 믿음)**. 중간 '모름' 칸을 건너뛰고 바로 '불신'으로 가면 안 됨.
- 둘을 붙이면 "매개변수 = 종속변수" 순환 지적. 별개여야 매개 성립.
- 미끄러지는 습관: 이론 넣을 때 IV 언어("기여도를 정확히 평가받지 못한다")로 되돌아가기 / "불확실을 의심"처럼 제자리 돌기 → UMT의 '절차를 더 따진다'는 행동을 넣어 다음 단계로.

## 4. MOD(조절) 구조 — 덧셈이 아니라 곱셈

- 걸리는 위치: **MV→DV 경로** → PROCESS Model 14.
- 작동: MOD 높으면 MV→DV 기울기 완만(신뢰 덜 하락), 낮으면 가파름.
- 왜 완화: 명확한 절차 설명이 **불확실성 자체를 낮추기** 때문.

```
DV = a + b1·(MV) + b2·(MOD) + b3·(MV × MOD)
```
- b3 = MV×MOD 상호작용항 ← **이 하나만 "조절효과"**. H4 지지 = b3 유의.
- 조절이 곱셈인 이유: MOD가 MV의 기울기 자체를 바꿈. Model 14 결과표에서 먼저 볼 숫자 = 상호작용항.

## 5. 가설별 근거의 강약

- H1 (모호성→불확실성): 기대원리로 지지. **약점** — '성과 기대'를 '평가 기대'로 확장 → 논리(연역)로 논증 필수(회피 불가).
- H2 (불확실성→공정성 저하): UMT가 이미 실증. **가장 튼튼.**
- H3 (매개): H1+H2면 자동. PROCESS Model 4.
- H4 (조절): Erdogan·Kim이 주효과는 지지하나 조절 형식은 직접 실증 아님 → 한계 명시. 지도교수께 유지 여부 질의.

## 6. 연구의 위치 — "작은 돌 하나"

- 새 이론 창출 아님. 성숙한 3이론(귀인·UMT·Colquitt)을 AI 협업 맥락에 적용 + 연결 실증.
- 이론 기여 = "귀속 모호성 → 평가 불확실성" 새 연결. UMT는 불확실성의 출처를 말한 적 없음.
- 차별 = 세 조건 동시: (1)AI 협업 도구 (2)사후적 귀속 모호성 (3)절차공정성.
- 난이도의 실체 = 이론 개수 아님(방법 하나). 진짜 난이도는 H4(조절) → 축소 시 첫 후보.

## 7. 5대 문제와 성격 (회피 가능 여부)

| 문제 | 성격 | 처리 |
|---|---|---|
| 1. H1 '평가 기대' 확장 | **논증 필수 (회피 불가)** | 논리 한 문단. 문헌 있으면 인용, 없으면 "본 연구 제안"으로 명시 |
| 2. 평가 불확실성 척도 | **실행 블로커** | 척도 확보 (미해결) |
| 3. 시나리오 교란 통제 | **실행 블로커** | AI 사용량이 IV와 동반 변동 → 통제 설계 필요 |
| 4. 단일 시점 인과 한계 | 한계 (회피 가능) | 횡단 설계 한계로 명시 + MV를 DV보다 앞 배치 |
| 5. H4 기여 크기 | 전략 (선택) | 매개만 축소 가능. 지도교수 상의 |

착수 순서: **1(논증) → 2(척도) → 3(교란) → 4·5(정리)**.

### 파일별 수정 방향 (V16 → V17)

1. **construct-definition** — II장 '심리적 무력감' → '지각된 평가 불확실성'으로 전면 교체. 정의·경계·What-It-Is-Not(불확실성 기준으로: 귀속모호성/역할모호성/직무불안정성과 구분) 재작성. IV→MV를 기대원리로. **IV-MV 순환 차단 문장(대상·시점 분리) 명시.**
2. **research-model** — Overarching 4이론 → 3이론(귀인·UMT·Colquitt), COR 제거. MV=평가 불확실성. H1 근거를 기대원리로, H2는 UMT 유지·강화, H3 근거 정리. H4 화살표를 'MOD→(MV→DV 경로)' 조절로 정확히 표기.
3. **logic-architecture** — Layer 2(b) COR→기대원리(모호성→불확실성)로 재구성. Layer 3에서 accuracy 언급 제거(consistency·bias suppression 중심). Layer 4 불확실성 기준으로. 공헌 문구 3이론으로.
4. **measurement-items** — MV 문항 틀을 불확실성으로 교체(**실제 문항은 척도 확보 후 = 2단계**). **DV에서 accuracy 1·4번 제거 → consistency·bias suppression 중심 재작성(AI 미언급).**
5. **Literature_Map** — Hobfoll 제거/보조 하향, Van den Bos 핵심 격상, Spreitzer 척도후보 삭제. §2.3을 기대원리로 재편. 평가 불확실성 척도 자리 + 기대원리 문헌 자리 신설.
6. **paper-feature-matrix** — 무력감→불확실성 문구 교체, Spreitzer 행 제거/대체, Research Gap 문장 갱신, Leonardi 용도 재기술.
