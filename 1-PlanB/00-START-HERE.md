## 1. 한 문장

**AI 협업에서 발생하는 성과 기여 귀속 모호성이, 구성원의 지각된 평가 정확성에 영향을 미치는지를 기존 연구 흐름 위에서 검증한다.**

---

## 2. 왜 이 작업선이 있는가

| | |
|---|---|
| **Plan A** | 시나리오 실험 · IV → MV(평가 불확실성) → DV(절차공정성) + 조절. 몇 개월간 파온 것이고 **연구자가 하고 싶은 방향** |
| 🔴 **A의 문제** | 척도 셋을 새로 만들어야 한다. 최소 6~7주 — **학위 일정 안에 완결을 보장하기 어렵다** |
| **Plan B** | **선행연구의 구조와 방법론에 기대는 형식.** 문제의식은 그대로 두고 종속변수를 바꾼다 |

📌 **핵심 동기** — 기여의 크기가 아니라 **「지지받는 형식」과 「일정 안의 완결」**이다.

⚠️ **B는 A를 버리는 것이 아니다.** B로 「귀속 모호성이 평가 지각에 영향을 준다」를 먼저 확인하면, **A의 매개 구조는 그 위에서 후속으로 세울 수 있다.** 순서를 바꾸는 것이다.

## 4. 현재 상태 — 2026-08-26 기준

### 확정된 것

| | |
|---|---|
| 문제의식 | AI 협업 · 기여 귀속 모호성 · 성과평가 |
| DV | **지각된 평가 정확성** (perceived appraisal accuracy) |
| 구조 | 기존 선행요인 통제 → 귀속 모호성 추가 → **ΔR²** |
| 방법 | 설문 횡단. **시나리오·무작위 배정 없음** |

### 🔴 미확정 — 이것부터 푼다

| # | 무엇 | 왜 |
|---|---|---|
| **1** | **Heneman et al.(1987)의 ratee 요인이 무엇을 포함하는가** | 공백 진술의 강도가 여기서 정해진다 |
| **2** | Findley et al.(2000)의 **incremental variance 검정 방식** | 본 설계 ΔR² 논리의 방법론 선례 |
| ~~3~~ | ~~Vest et al.(1995) 4문항의 실제 출처~~ | 🟢 **[08-26] 해결 — 그 논문에서 개발된 것으로 확정.** `04-sources` §1 |
| **4** | 🔴 **IV·DV 판별 경계** | 문항을 잘못 쓰면 DV를 뒤집어 묻는 것이 된다 |

### ❌ 아직 쓰면 안 되는 표현

| 표현 | 이유 |
|---|---|
| 「아무도 평가 대상 쪽을 보지 않았다」 | Heneman에 **ratee**가 있다 |
| 「변수가 아니라 새로운 설명 수준이다」 | 문헌 지도 완성 전이다 |
| 「선행요인 여섯 개를 다각도로 검증한다」 | 🔴 **그 여섯은 통제변수다.** 본 연구 IV는 하나다 |
| 「인사조직 최상위 저널」 | Tsai & Wang은 국제 HRM 저널의 peer-reviewed 실증연구다 |
| 「산출물 자체가 개인 기여로 분해되지 않는다」 | 절대적이다. **「분리하기 어려운 상황이 발생할 수 있다」** |

### ⭕ 현재 쓸 수 있는 공백 진술

> **AI 협업에서 산출물의 기여 귀속 모호성이 구성원의 평가 정확성 지각에 미치는 영향을 검증한 연구는 확인되지 않는다.**
